## Decisions

固废主机按 SQLite 文件路径协调进程内业务写入。写入口在事务开始前进入队列，提交或回滚并释放事务后归还资格。嵌套调用参与现有 UoW，避免事件处理等待自身持有的写入资格。核对配置中的内核与产品 Context 是否使用同一实际连接与事务。

建单与初始恢复状态在同一个短事务内提交。之后的匹配和恢复状态更新由外层按顺序调度。恢复状态辅助方法只更新状态，不自行开启 UoW。设备、照片和网络操作位于本地写事务以外。后台轮询在取得远端结果后使用短写入阶段保存。

## Risks

需要验证 ABP 提交前发布事件的路径，避免嵌套写入造成自等待。多个进程仍可能争用同一个 SQLite 文件。持续外部锁的处理策略和现场持锁方归因分别跟踪。
