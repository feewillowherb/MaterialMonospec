## Context

Admin 的 `/` 与 `/projects` 是城管项目页，标题为「城管项目」。列表不按产品过滤，5020 行与 5001 行出现在同一张表，产品列区分「资源化」和「城管」。5020 行已经不进入城管称重页。侧栏另有 Recycle 设备在线页，那不是项目列表。

## Goals / Non-Goals

**Goals:**

- 增加独立路由和菜单，只展示 ProductCode 5020 的项目。
- 页面能力与现有项目页对齐：搜索、在线状态、同步开关、设备详情。
- 5020 行不提供城管称重入口。

**Non-Goals:**

- 不从现有项目管理页移除 5020 行。
- 不新增项目、不改拉取、不改 Recycle Web 绑定。
- 不把 5020 行接到称重记录、卡口或异常审批。

## Decisions

- 新路由 `/recycle-projects`，菜单标题「资源化项目」。与现有项目页共用列表实现，按当前路由决定是否只查 5020，避免复制整页。
- `GovProjectListRequestDto` 增加可选 `ProductCode`。未传时保持现有全量查询，称重等页面的项目下拉不变。
- 5020 过滤使用精确相等。不套用 5001 的区域条件，也不把 ProductCode 0 算作 5020。
- 同一组件在 `/` 与 `/recycle-projects` 之间切换时重新加载，并重置搜索、状态筛选和页码。

## Risks / Trade-offs

- [现有项目页仍同时列出 5020] → 独立页是新增入口，既有「列表可见 5020」要求保持不变。
- [路由复用同一组件导致列表不刷新] → 监听地址变化，产品范围变化时重新查询。
