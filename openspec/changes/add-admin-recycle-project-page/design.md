## Context

Admin 的 `/` 与 `/projects` 是城管项目页，标题为「城管项目」，只列出 5001。`/recycle-projects` 只列出 5020。5020 行已经不进入城管称重页。侧栏另有 Recycle 设备在线页，那不是项目列表。

## Goals / Non-Goals

**Goals:**

- 增加独立路由和菜单，只展示 ProductCode 5020 的项目。
- 页面能力与现有项目页对齐：搜索、在线状态、同步开关、设备详情。
- 5020 行不提供城管称重入口。

**Non-Goals:**

- 城管项目页只查询 5001，历史 ProductCode 0 视作 5001。资源化项目页只查询 5020。
- 两套目录密钥都存在时，项目拉取同时写入 5001 与 5020，避免城管页没有数据。
- 不把 5020 行接到称重记录、卡口或异常审批。

## Decisions

- 新路由 `/recycle-projects`，菜单标题「资源化项目」。与现有项目页共用列表实现，按当前路由决定是否只查 5020，避免复制整页。
- 城管项目页传 ProductCode 5001。资源化项目页传 5020。未传产品的查询仍返回全部，称重等页面的项目下拉不变。
- 5001 过滤包含 ProductCode 0。5020 过滤使用精确相等。
- 同一组件在 `/` 与 `/recycle-projects` 之间切换时重新加载，并重置搜索、状态筛选和页码。

## Risks / Trade-offs

- [现有 5020 行已在库中] → 城管页改为 5001 过滤后不再显示这些行。
- [只配置了 5020 同步时城管页为空] → 两套目录密钥都存在时同一轮拉取写入 5001 与 5020。
