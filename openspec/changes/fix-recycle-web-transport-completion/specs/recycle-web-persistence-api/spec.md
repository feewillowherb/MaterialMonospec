## ADDED Requirements

### Requirement: Web 用持久标识补全运输单

Web SHALL 将合同、合同明细及材料的持久标识提交给服务。服务 SHALL 校验明细属于所选合同、材料与明细一致，并从项目内可信资料生成快照。合同页面 SHALL 支持同一合同的多运输人保存和回读。

#### Scenario: 补全后回读

- **WHEN** 用户选择项目内有效合同明细和材料并保存
- **THEN** 台账回读显示所选关联及其快照

#### Scenario: 关联不一致

- **WHEN** 提交其他项目的对象或其他合同的明细
- **THEN** 请求被拒绝且原运输单保持原有数据

#### Scenario: 合同多个运输人

- **WHEN** 用户保存一份含多运输人的合同并重新打开
- **THEN** 页面回读完整的运输人列表
