## Context

Web 补全 DTO 把合同、明细、材料 ID 全部置空，只传文本，服务的关联 ID 校验无法覆盖这条页面路径。合同页面写入形状也只能携带一个运输人，无法兑现现行多运输人场景。

## Goals / Non-Goals

**Goals**

- 用项目内真实合同、合同明细、材料标识完成运输单；补齐合同多运输人的页面写入与回读。

**Non-Goals**

- 生产部署及提交合入单独授权。

## Decisions

页面从当前项目的资料中选择，服务根据可信项目查询并校验合同、合同明细与材料的一致性，由领域类型保存快照。沿用逻辑 ID。合同页面对多运输人读写采用持久 ID 或既有合同服务形状。

- 以实际业务链路的可观察结果判定验收，并记录环境、单据标识和服务响应摘要。138 历史证据见 [调研总览](../../../docs/2026-11-19-recycle-client-to-web-fev/00-调研总览.md)，部署 Run `deploy-urban-lab-138/2026-11-19T164403` 仅用于追溯当时部署。
