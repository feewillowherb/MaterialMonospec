## Context

车辆、合同、日产量与运输的 Web 上报路由固定调用 NotSent，尚未通过这些入口向外部平台发送。

## Goals / Non-Goals

**Goals**

- 查证所需市平台接口及测试授权，接通端到端流程所需的车、合同、日产量和运输上报，记录每次真实尝试及平台结果。

**Non-Goals**

- 生产部署及提交合入单独授权。

## Decisions

应用服务负责项目权限、调用外部 API 与记录尝试。按已核实的接口契约决定业务方向、单位、成功码和可重试行为。对超时等结果未知的情况先核对平台记录或使用其支持的幂等键。运输联调以真实接收并补全的单据为输入。
