# strategic-fallback

Trait：策略性挂起。核心原则：**策略性挂起优先于无意义的代码**。

适用范围：本仓及 `repos/` 下子仓的大规模遗留代码修改、复杂调用链改动。  
加载时机：修改过程中遇到阻塞（跨多条复杂领域链且未批准、关键事实缺失、高风险无法在当前范围验证）时 **MUST** 先读本文件再继续写代码。  
本 trait 仅留在 monospec `traits/`（编排仓行为契约）；**不要**同步到子仓 C# `traits/` 副本。与 `guess-governance`、`intake-parking` 同时生效时，以**更严格**者为准。

## 核心原则

### 1. 零代码污染

**MUST NOT** 用假业务逻辑、桩算法、假返回值或胶水代码假装复杂障碍已经解决。  
直接写进主代码路径的未完成逻辑，一律视为**技术债务与代码投毒**。

### 2. 策略性挂起优先

修改大规模遗留代码或穿越高度复杂的调用链时，若遇到阻塞（状态机死锁、未预期的跨域依赖、未验证的高风险假设），**MUST** 用防守型外壳隔离该能力，**MUST NOT** 写伪实现。

### 3. 不可变基线保护

既有生产路径 **MUST** 保持 100% 稳定、完整。临时绕行 **MUST NOT** 削弱或改变已验证行为。

## 触发条件

大规模代码修改过程中出现以下**任一**情况，**MUST** 停止完整代码生成，并激活策略性挂起：

- 修改打破既有基线契约或测试，且修复需要未经批准、跨多条复杂领域链的改动。
- 关键业务规则、边界情况或下游依赖（缺失事实）未定义或未验证。
- 高风险操作（财务操作、多节点数据变更、并发锁）无法在当前 change 范围内完整验证。

未触发时，按当前 change / 任务正常实现；**不要**为了用本协议而扩大挂起范围。

## 防守型外壳（三选一）

触发后 **MUST** 且只能采用下列模式之一。语言无关。

### 模式 A：功能开关外壳（优先）

对外暴露新签名或组件，但通过功能开关或配置把执行路由回已验证的遗留基线路径。

- **MUST NOT** 在关闭的分支里写未完成代码。

### 模式 B：显式挂起 / 阻断外壳

对复杂链中尚不能安全实现的新接口 / 签名，提供调用即明确中止的防守外壳：

- 返回标准「未实现 / 功能已挂起」错误或异常，并带可操作的运行元数据。
- 记录清晰的运行告警：挂起原因 + 目标解决路径。
- **MUST NOT** 用硬编码假数据假装进展（空列表、假 token、成功布尔值等）。

### 模式 C：声明式边界斩断

在契约或提案层截断修改范围：

- 把被阻断的依赖或复杂链项在当前 change 中明确标为 **Out-of-Scope**。
- 把被阻断需求作为 **Decision Needed** 交给干系人评审。

## 与相邻约定的边界

| 相邻 | 本 trait 不替代 |
|------|-----------------|
| `intake-parking` | 碎片需求收件与 INT 序号；本 trait 管的是**实现受阻时的代码外壳**，不是需求停车场 |
| `guess-governance` | 未确认细节视为假设；本 trait 禁止用假实现填补未验证高风险 |
| 「OpenSpec 与技术债务」 | 默认不把债务清扫塞进当前 change；触发本协议时同样 **MUST NOT** 借机扩范围 |

## Agent 输出协议

遇到复杂障碍时，**MUST NOT** 先写长篇解释或推测性代码。

响应 **MUST** 以如下结构开头（字段标题与标记保持不变，正文用中文）：

```
--------------------------------------------------
[🚨 STRATEGIC FALLBACK ACTIVATED]
- Barrier Diagnosis: [复杂调用链中阻塞的简短描述]
- Mitigation Path: [已采用的 Pattern A / Pattern B / Pattern C]
- Scope Decoupling:
  * Phase 1 (Current Scope Δ1): 安全防守外壳，以及不可变基线的保全。
  * Phase 2 (Follow-up Scope Δ2): 专用于解决该复杂链的后续任务。
- Action Items / Decisions Needed:
  1. [进入 Phase 2 所需的明确事实或批准]
--------------------------------------------------
```

输出该块之后，才可以写 Phase 1（Δ1）范围内的最小外壳改动。**MUST NOT** 在同一轮继续展开被阻断路径的伪实现。
