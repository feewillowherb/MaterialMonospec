# 04 · 改进建议与优先级

## 1. 原则（与仓库 trait 对齐）

1. **枚举优先**：所有持久化 Entity 的同步状态统一为 `SyncStatus` enum（含 `GovSyncData` 表结构）；禁止 Service 层 `0/1/2` 魔法值
2. **Nullable 有意义**：创建时即确定的字段 non-nullable（含 `ProId`、`SyncType`、`RetryCount`）
3. **类型归属行为**：状态迁移（如 `ResetGovSync`）写在 Entity 方法内，使用 enum 非 int
4. **项目标识**：`ProId` 全仓统一为 **non-nullable `Guid`**；创建/API/Urban 客户端必填；写入边界拒绝 `Guid.Empty`
5. **Legacy 移除 + WIP**：Legacy HTTP 业务实现 **移除**；端点/服务标记 **WIP**，**不入库**；完整兼容层见 [INT-006](../intake/2026-09/INT-006-legacy-gov-sync-reimplementation.md)
6. **停止双写**：Modern 路径 **仅写** `UrbanWeighingRecord`；**禁止**再向 `GovSyncData` 插入新行
7. **AccessCode 挂起**：`BuildLicenseNo` / `AccessCode` 重命名 — **本 initiative 不做**（见 D8、[INT-005](../intake/2026-09/INT-005-urban-entity-accesscode-rename.md)）
8. **分 change 落地**：遵循 OpenSpec + `openspec-git-workflow`
9. **Initiative 基线**：`UrbanManagement` 仓 **`dev-urban-entity-semantic`**（Mode B）；P0–P2 各 change squash 入 `dev-*`；全部归档后 promote 入 `main`

## 3. 分阶段建议

### P0 — SyncStatus + RetryCount + Legacy WIP

| 项 | 动作 | 涉及 |
|----|------|------|
| 通行 / 称重 | `SyncType` → `SyncStatus` non-nullable；`ClientSyncType` 同上 | Entity, DTO, Manager, AppService |
| `GovSyncData` | 表结构：`SyncType` enum、`SyncNumber`→`RetryCount`；**无新 Insert** | Entity, migration |
| RetryCount | 通行、称重、`GovSyncData`：`int?`→`int`；`ClientRetryCount`→`int` | 全仓 |
| API | `SyncStatus` JSON 字符串名 | 序列化配置 + Blazor |
| Legacy | **WIP stub，不入库**（D18）；移除 `GovSyncData` insert（D19） | `LegacyApiController`, `LegacyGovSyncAppService` |
| 魔法值 | 全部 `0/1/2` → enum | Service |

**预期**：**M 档**

### P1 — 移除 FdBuildLicenseNo

| 项 | 动作 |
|----|------|
| 移除 | `GovProject.FdBuildLicenseNo` 删列 + 清引用（Hub/JWT/Pull/UI/校验） |
| **不做** | AccessCode / BuildLicenseNo 改名（INT-005） |

**预期**：**S–M 档**

### P2 — ProId + SiteType + IsSyncEnabled

| 项 | 动作 |
|----|------|
| `ProId` | required `Guid`（含 `GovSyncData`、在线态）；非法历史行忽略 |
| `SiteType` | 类型 → `UrbanSiteType`，**列名/属性名不变** |
| `EnableSync` | → **`IsSyncEnabled`**，`bool` non-nullable；DB 列物理 rename |
| **不做** | `VehicleType` / `PlateColor` |

**预期**：**M–L 档**

### P3 — GovSyncData 强类型（可选，只读表）

历史 `GovSyncData` **只读**前提下可选：

| 项 | 动作 |
|----|------|
| `SnapTime` | `string?` → `DateTime?` 或删列 |
| `GoodsWeight` | `string?` → `decimal?` |

**预期**：**M 档**

## 5. Legacy / 双写边界

```text
Before (移除):
  Legacy HTTP → UrbanWeighingRecord + GovSyncData 双写

After (本 initiative):
  Legacy HTTP → WIP 响应，不入库
  Modern Receive API → 仅 UrbanWeighingRecord（+ 附件）
  GovSyncData → 历史只读；schema 可随 P0 enum 化，无新 Insert

Future (INT-006):
  Legacy 兼容层重新设计，仍禁止恢复双写
```
