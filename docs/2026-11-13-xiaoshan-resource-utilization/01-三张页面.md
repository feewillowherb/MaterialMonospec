# 三张页面

创建日期：2026-11-13。生命周期：ACTIVE。知识状态：CONFIRMED（画面摘录）/ INFERRED（mock 行为）。

画面摘录来自 `_tmp/萧山资源化利用/` 的三张图。字段和按钮以图为准。图上的车牌、合同号、人名和电话是样例，写入 mock 种子即可，不表示已有业务数据。

2026-11-16 确定这三张页面用 Vue 3 + Element Plus 实现。列表、分页、对话框、上传和状态标签使用 Element Plus 组件。车辆和合同 mock 由本站 API 提供，Vue 从该 API 获取。

## 共用外壳

前两张图是同一套外壳。2026-11-16 收窄：外壳只承载这两张列表和新建合同对话框。

- 顶栏为紫色。左侧是菜单按钮和刷新。图上的标题文字是「渣土消纳一体化平台」。右侧是用户「於挺」和下拉。本站产品名称是「萧山资源化利用网页端」，登录页使用该名称。
- 左侧深色菜单只有两项：车辆管理、合同管理。图上的消纳场地、车运管理、生产管理、运输清单、系统管理不出现。
- 内容区顶部是页签。页签只在该页被打开后出现，标题为「车辆管理」或「合同管理」。当前页签有下划线。未打开的页面不留空标签，也不预留「仪表盘」。
- 登录后打开车辆管理，此时页签栏只有「车辆管理」。从菜单打开合同管理后，页签栏才出现「合同管理」。关掉页签后，该标签从页签栏消失。
- 列表区是白底卡片：筛选行、工具按钮、表格、底部分页。

登录成功后的用户名取本次 SSO 会话里的用户名。图上的「於挺」只是样例。

## 车辆管理

路由建议 `/vehicles`。页签标题「车辆管理」。

筛选行：

| 控件 | 占位或默认 |
|------|------------|
| 车牌号 | 请输入车牌号 |
| 运输人 | 请输入运输人名称 |
| 状态 | 全部状态 |
| 搜索 | 绿色按钮 |
| 重置 | 清空三个条件并回到第一页 |

工具行：

- 「录入车牌号」：绿色。打开一个只存在于内存中的录入区，字段与表格列一致（车牌号、皮重、运输人、电话、车辆状态）。保存后追加到当前列表。
- 「批量导入」：蓝色。按钮可见。本单不解析文件。
- 「批量删除」：橙色。删除已勾选的 mock 行。未勾选时不删除。

表格列：勾选、序号、车牌号、皮重(吨)、运输人、电话、车辆状态、录入时间、状态、操作。

- 车辆状态两种标签：「未运输」为橙色，「运输中」为绿色。
- 状态列图上均为绿色「启用」。
- 操作：「编辑」橙色，「删除」红色。编辑改当前行；删除去掉当前行。都只改内存列表。

分页在表格下方：页码、上一页、下一页、跳转到指定页、每页条数。图上是每页 20 条，并显示总条数。筛选和分页都在内存列表上完成。

图上可见的种子行包括浙 DQ04158、浙 DF8665、浙 DE5145、浙 DY5172、浙 DV4522 等，皮重约 18.2–18.5 吨，车辆状态在「未运输」和「运输中」之间交替，录入时间集中在 2026-06-24。实现时按图抄入一组固定种子，条数不必凑满图上的 262 条。

## 新建合同

这是合同列表上的对话框，不是独立路由。标题「新建合同」，右上角关闭。

### 合同基本信息

两列。

| 字段 | 图上的状态 |
|------|------------|
| 合同编号 | 空，占位「请输入合同编号」 |
| 签订日期 | 空，占位「请选择签订日期」 |
| 生产方 | 已填「浙江坤舆生态科技有限公司」 |
| 购买方 | 空，占位「请输入购买方名称」 |
| 运输方 | 空，占位「请输入运输方名称」 |
| 收货地址 | 空，占位「请输入收货地址」 |

生产方的预填值写在对话框初始状态里。用户可以改。

### 合同附件

标签「PDF附件」。按钮「上传PDF附件」。旁注：「未上传附件（仅限PDF格式，最大20MB）」。

下方提示：「温馨提示：请将多张合同扫描图片打包到一个PDF文档中保存上传，方便整体查阅。」

浏览器只接受扩展名为 `.pdf` 且不超过 20MB 的文件。通过后，旁注改成该文件名。文件留在浏览器本次编辑中，不上传到 Attachment 服务，也不写入磁盘。超过大小或不是 PDF 时，对话框内提示，不替换已选文件。

### 产品明细

表头：产品名称、用途、单价(元)、总量(吨)、总金额(元)、操作。

- 默认一行。产品名称是可输入的下拉，占位「选择或输入产品名称」。用途、单价、总量可编辑。总金额只读，由单价乘总量得到；缺任一输入时留空。
- 行末是删除。只剩一行时删除将该行清空，不把表格收成零行。
- 「添加产品」在表格下方，追加一行空明细。

### 保存与重置

底部居中：「保存」绿色，「重置」白色。

- 保存：用当前表单追加一条合同 mock。合同编号、购买方、收货地址为空时不关闭对话框，并在对话框内标出这些空字段。产品明细至少保留一行；名称和总量都空的行不写入明细。保存成功后关闭对话框，合同列表能看到新行，上报状态为「已发送」，附件列按是否选择了 PDF 显示「查看」或未上传。
- 重置：恢复打开时的空表单，生产方回到「浙江坤舆生态科技有限公司」，附件清空，明细回到一行。

编辑已有合同时复用同一对话框，标题仍可用「新建合同」的版式，字段填入该行。本单不另做一张编辑图。

## mock 数据放在哪里

列表种子放在 `UrbanManagement.XiaoShanResource` 进程内。Vue 通过本站 API 获取和修改，不放进 `UrbanManagement.Core`，不注册成 AppService，不注入 Repository。刷新页面后再次请求 API。进程重启后 API 回到种子数据。
