# 01 · 现状耦合与破坏面

## 配置模型

| 类型 | 路径 | 今日行为 |
|------|------|----------|
| 全局厂商 | `repos/MaterialClient/src/MaterialClient.Common/Configuration/SystemSettings.cs` 的 `LprDeviceType` | 默认 `Hikvision`；JSON 有 `LprDeviceTypeJsonConverter` |
| 单台设备 | `LicensePlateRecognitionConfig.cs` | **无** `DeviceType`；只有 Name / Ip / Direction / 认证 / Channel / GateIo |
| 添加对话框 | `MaterialClient.UI/ViewModels/AddLprDialogViewModel.cs` | 构造函数接收 `LprDeviceType`，只影响字段可见与默认值，**不写入** Result |
| 设置主 VM | `SettingsWindowViewModel` | 全局 Combo 绑定；`AddLpr` / `EditLpr` / `TestLprCapture` 都传当前 `LprDeviceType` |

枚举定义：`Entities/Enums/LprDeviceType.cs`（Hikvision / Vzvision / Huaxiazhixin）。

## 运行时全部读全局（破坏核心）

| 调用点 | 行为 |
|--------|------|
| `DeviceManagerService.StartAsync` | `if Hikvision` 只起海康 LPR；`if Vzvision` 只起臻识。**互斥**，不能混厂商 |
| `WeighingCaptureService` | `GetDevice(settings.SystemSettings.LprDeviceType)` 再对配置列表抓拍 |
| `AttendedWeighingViewModel.CheckLprOnlineStatusAsync` | 同一全局 type + `GetOnlineStatuses(deviceType, configs)` |
| `SharedDeviceStatusTracker.CheckLprOnlineStatusAsync` | 同上 |
| `SettingsWindowViewModel.TestLprCaptureAsync` | `GetDevice(LprDeviceType)` 测当前行，类型仍用全局 |
| `ILprDeviceResolver.GetDevice` | 按传入枚举解析实现；调用方今天几乎都传全局 |
| `GateIoControlService.OpenGateViaLprSdkAsync` | 注释写明类型来自全局；实现走 `_vzvisionLprService` |
| `SettingsWindow.axaml.cs` | `WhenAnyValue(LprDeviceType)` 改**整张** LPR 表列可见性 |

`HikvisionService` 注释已说明摄像头服务与 `LprDeviceType` 无关；LPR 监听服务仍受全局门控。

## 破坏性分级

| 面 | 级别 | 说明 |
|----|------|------|
| 已部署 JSON | **低** | 行上新增 `DeviceType`；加载时用旧 `SystemSettings.LprDeviceType` 回填。过渡期可继续写全局字段，避免老客户端读空 |
| 已部署行为（全站一种厂商） | **低** | 回填后与现在一致 |
| 契约「改全局 Combo = 已添加设备全部换厂商」 | **高（有意打破）** | 改成编辑单台才换类型 |
| `DeviceManager` 互斥启动 | **高** | 混厂商必须两种 SDK 都能 Start；联调/泄漏/双监听是最大回归点 |
| 设置 DataGrid 列 | **中** | 不能再按一个全局 type 藏整列；混厂商要按行或常显列 |
| 在线灯「任一 LPR 在线」 | **中** | 语义是否仍 any-online 需产品确认 |
| 跨仓 | **无（本期）** | 不改 UrbanManagement 库表 |

无 EF 表迁移；设置在 `SettingsEntity` JSON。不是拆 WinExe。

## 建议实现边界（控制破坏面）

1. `LicensePlateRecognitionConfig`（及对应 ViewModel）增加 `DeviceType`。  
2. `AddLprDialog`：类型 ComboBox；`WhenAnyValue` 驱动海康/臻识字段与默认值；Save 写入行。编辑时用该行类型，不用全局。  
3. 设置页移除全局「车牌识别设备类型」。  
4. DeviceManager / 抓拍 / 在线 / 测试抓拍 / 道闸门控：按 **该行** `DeviceType` 解析。DeviceManager 按配置中**实际出现的类型**启停，而不是 if-else 全局一份。  
5. 加载迁移：行缺省 → 填当时的 `SystemSettings.LprDeviceType`。  
6. OpenSpec：更新 `openspec/specs/settings-ui/spec.md`（及若有 LPR 能力 spec）。  
7. **不做**：卡口/成品独立 entity、萧山上报链路、为「简化」而继续只存全局。
