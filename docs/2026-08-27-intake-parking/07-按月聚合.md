# 07 · 按月聚合

条目按**登记日**所在自然月放入子文件夹；**消化仍按 `theme`**（跨月合并）。

## 文件夹命名

| 规则 | 示例 |
|------|------|
| 格式 | `YYYY-MM` |
| 推导 | 由 INT 的 `created`（`YYYY-MM-DD`）取年月 |
| 字段 | `intake_month` 必须与文件夹名一致 |

例：`created: 2026-08-27` → `2026-08` → 路径 `docs/intake/2026-08/INT-004-….md`

## 路径

```text
docs/intake/
├── README.md          ← 全局：theme 索引 + 月目录表 + Next ID
├── _template.md
└── 2026-08/
    ├── README.md      ← 可选；仅该月条目
    └── INT-001-….md
```

## 登记步骤

1. 定 `created`（通常当天）  
2. 取年月 → `intake_month`（`YYYY-MM`）  
3. 若无文件夹则创建 `docs/intake/<YYYY-MM>/`（建议加该月 `README.md`）  
4. 写入 `INT-<NextID>-<slug>.md`  
5. 更新根 `README.md` 与月 `README.md`

## 索引双维

| 维度 | 用途 | 位置 |
|------|------|------|
| **theme** | 消化 → Epic | 根 `README.md` §按 theme |
| **登记月** | 挂起期收件、月底复盘 | 根 `README.md` §按月 + 各月文件夹 |

## 与 `parked_until` 的关系

| 字段 | 含义 |
|------|------|
| `intake_month` / 月文件夹 | **何时登记** |
| `parked_until` | **计划何时消化**（可与登记月不同） |

## 不做

- 按 **day** / **ISO week** 建子目录（draft 文件名可用日期，但仍落在月目录 `drafts/` 下）  
- 按 **月** digest（消化单位仍是 theme，不是 month）  
- 移动已登记 INT 到其他月文件夹（`created` 不变则路径不变）

## 推导（参考）

由 `created` 直接取前 7 位即可：`2026-08-27` → `2026-08`。
