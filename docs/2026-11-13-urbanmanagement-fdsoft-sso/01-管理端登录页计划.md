创建日期：2026-11-13。生命周期：ACTIVE。知识状态：PENDING_VALIDATION。

本文件是后续实现计划，不是已落地的产品行为。2026-11-13 曾开始直接改登录页代码，已回滚；实现须另开 OpenSpec change，并在 Human `APPROVED` 之后再改 `repos/UrbanManagement`。

## 要解决的问题

已归档的 `add-urbanmanagement-web-sso` 把管理端登录做成了账号和密码两个输入框。现场页面把密码标成了「口令」，计划中的文案是「密码」。现场使用后有两处缺口：

- 登录页没有图形验证码。
- 进入管理页后无法退出。页眉里的退出表单写在 Blazor 组件内，点击不会整页提交到 `/logout`，本地 Cookie `UrbanAdmin.Session` 因此不会被清掉。
- 登录后的页眉没有显示当前用户名。不需要个人中心、资料页或改密入口。

## 参考

登录窗口以 BasePlatform 登录页为准，不以凡东 CRM 登录页为准。

| 参考 | 路径 |
|------|------|
| 页面结构 | `repos/FdSoft.BasePlatform/FdSoft.BasePlatform/Views/Home/Login.cshtml` |
| 验证码签发与登录校验 | `repos/FdSoft.BasePlatform/FdSoft.BasePlatform/Controllers/HomeController.cs` 的 `GetImg`、`Login` |
| 校验顺序 | `repos/FdSoft.BasePlatform/FdSoft.BasePlatform.Service/BasePlatform/BasePlatformService.cs` 的 `Login`：先对验证码，再 `POST /GetToken` |

BasePlatform 的做法：

1. 页面有用户名、密码、图形验证码输入框，验证码图片在输入框右侧，点击图片重新获取。
2. `GetImg` 生成验证码，把文本按 id 放入缓存，约 60 秒过期，页面只拿到图片和 id。
3. 提交时先比对验证码。过期提示「验证码已过期」，不匹配提示「验证码错误」，比对时忽略大小写。
4. 验证码通过后才调用 SSO `GetToken`。验证码字段不代替密码校验。

不要照搬该页上的相关下载、微信/Android/iOS 图标、记住密码、备案页脚和 Logo 图。Urban Admin 标题保持「萧山城管对接平台」。

## 计划中的登录页

登录页仍由 Admin 自己渲染，浏览器只把账号、密码和验证码交给 Admin。Admin 再按已有约定调用 SSO：`switchType=0`、`productType=2`、`toProductIds` 只含配置的 Web 产品编码。

- 字段顺序：用户名、密码、图形验证码、登录按钮。密码框的可见文案是「密码」。
- 验证码在 Admin 进程内签发和校验，不改 FdSoft.SSO，也不把验证码文本写进页面、日志或 Urban 数据库。
- 验证码未通过时不调用 `GetToken`，也不创建 `UrbanAdmin.Session`。
- 验证码通过但 SSO 拒绝、不可用或产品不匹配时，仍只显示登录失败，不创建会话。
- 失败后换一张验证码。

## 计划中的页眉

登录成功后，管理页右上角显示本次会话里的用户名，旁边是「退出」。

- 用户名来自现有 Admin Cookie 中的用户名声明，不新增个人中心。
- 退出必须让浏览器整页请求 `/logout`，由该请求删除 `UrbanAdmin.Session` 并回到登录页。
- 退出仍不调用 SSO `logout`，也不删除 SSO Redis 会话。
- 退出后，管理页、Blazor Hub 和管理 API 恢复为未登录行为。

- 切换项目或切换产品。
- 改 Gateway 路由，或给客户端上传、称重、实时通道加登录页。
- 修改 FdSoft.SSO、FdSoft.BasePlatform、MaterialClient。
