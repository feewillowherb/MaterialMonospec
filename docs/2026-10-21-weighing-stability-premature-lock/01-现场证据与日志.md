# 01 — 现场证据与日志

## 现场配置

与设置页 / 启动日志一致：

| 参数 | 值 | 含义 |
|------|-----|------|
| `MinWeightThreshold` | 0.5 t | 超过则 `OffScale` → `WaitingForStability` |
| `WeightStabilityThreshold` | 0.05 t | 允许极差 = **0.05 × 2 = 0.1 t** |
| `StabilityWindowMs` | 3000 | Rx `Buffer` 时间窗（回看上限，非最短等待） |
| `StabilityCheckIntervalMs` | 200 | 滑窗推进间隔 |

日志原文示例：

```text
Loaded configuration - MinWeightThreshold: 0.5, WeightStabilityThreshold: 0.05,
StabilityWindowMs: 3000, StabilityCheckIntervalMs: 200
```

## 主案例：2026-10-21 15:02（过早锁重）

来源：`_tmp/1021/MaterialClient.Urban-20261021.log`

| 时间 | 事件 |
|------|------|
| 14:59:37 | 进程启动，加载上述配置，开始监控地磅 |
| 15:02:36.774 | `Entered WaitingForStability (ascending), weight: 0.550t` |
| 15:02:37.547 | `Converting … → WeightStabilized`，`IsStable=true`，间隔 **~773ms** |
| 15:02:37.548 | 建单重量 **0.545t** |
| 15:02:37.768 | `Created weighing record … ID: 6, Weight: 0.545t` |
| 随后 | 进入 `WaitingForDeparture`，**不再改重量** |
| 15:03:42 | 应用退出（现场重启） |
| 15:04:00.715 | 重启后同一场景判稳 **1.090t**（ID=7）← 接近操作员所述真重 ~1.05t |

要点：

- 锁重发生在爬升**中途平台**（0.54~0.55），不是终稳。
- 建单后状态强制 `WaitingForDeparture`，终重上来也不会改写本笔。
