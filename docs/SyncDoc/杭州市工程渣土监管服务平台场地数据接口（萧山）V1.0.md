## 第 2 章 对接接口详情

> **公共说明**
>
> - 请求方式为 `POST`，`Content-Type: application/json`。
> - 原文标注「请求公共参数：无」。
> - 示例基址为 `http://172.18.34.209:8899`（现场/联调环境以实际部署为准）。

### 2.1 车辆进出记录接口

| 项目 | 说明 |
|------|------|
| **名称** | 车辆进出记录 |
| **路径地址** | `/sapi/v1/inoutRecord/save` |
| **完整示例** | `http://172.18.34.209:8899/sapi/v1/inoutRecord/save` |
| **请求方式** | `POST`（`Content-Type: application/json`） |
| **请求公共参数** | 无 |

#### Request 参数说明

| 参数名称 | 类型 | 示例 | 描述 | 是否必填 |
|----------|------|------|------|----------|
| `carNo` | string | — | 车牌号（车牌未识别填「无」） | 是 |
| `carColor` | string | — | 车身颜色 | 否 |
| `carNoColor` | string | `黄` | 车牌颜色（黄、蓝、绿、黑、白）；车牌未识别填「无」 | 是 |
| `carType` | string | — | 车型（大车、小车） | 是 |
| `snapTime` | string | `yyyy-MM-dd HH:mm:ss` | 抓拍时间 | 是 |
| `snapImages` | Array | `base64`（`[大图, 小图]`） | 抓拍照片；去掉 Data URL 头标识 | 是 |
| `deviceID` | string | — | 设备编号（`01` 进，`02` 出） | 是 |
| `buildLicenseNo` | string | — | 场地唯一标识 | 是 |
| `siteType` | string | 默认 `1` | 场地类型（`1` 工地，`2` 消纳场） | 是 |
| `goodsWeight` | string | — | 货物重量（单位千克） | 否 |
| `areaCode` | string | `330109` | 场地所属区 | 是 |
| `spaceName` | string | — | 场地名称 | 否 |

#### Response 参数说明

返回数据类型：`object`，结构如下：

| 参数名称 | 类型 | 描述 |
|----------|------|------|
| `code` | code | 状态码；`200` 成功，其他失败 |
| `msg` | string | 描述信息 |
| `data` | object | 信息结构 |

#### 返回数据补充说明

部分 `code` 与 `msg` 对应关系：

| code | msg |
|------|-----|
| `501` | `xxx字段不能为空` |
| `502` | `xxx字段数据格式异常` |
