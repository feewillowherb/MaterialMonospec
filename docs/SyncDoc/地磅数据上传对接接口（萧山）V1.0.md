## 第 2 章 开放接口

> **公共说明**
>
> - 请求方式均为 `POST`，`Content-Type: application/json`。
> - 原文标注「请求公共参数：无」。
> - 示例基址为 `http://172.18.34.209:8899`（现场/联调环境以实际部署为准）。

### 2.1 接收上报数据

| 项目 | 说明 |
|------|------|
| **名称** | 接收上报数据 |
| **路径地址** | `/sapi/v1/inoutRecord/lantu/saveRecord` |
| **完整示例** | `http://172.18.34.209:8899/sapi/v1/inoutRecord/lantu/saveRecord` |
| **请求方式** | `POST`（`Content-Type: application/json`） |
| **请求公共参数** | 无 |
| **备注** | JSON 请求方式 |

#### Request 参数说明

| 参数名称 | 类型 | 参数描述 | 是否必填 | 取值范围 |
|----------|------|----------|----------|----------|
| `carNo` | String | 车牌号 | 是 | — |
| `carColor` | String | 车身颜色 | 否 | 绿、蓝、红 |
| `carNoColor` | String | 车牌颜色 | 是 | 黄、蓝 |
| `carType` | String | 车型 | 否 | 大车、小车 |
| `buildLicenseNo` | String | 场地标识 | 是 | 地磅安装时由平台运营单位提供 |
| `dataSource` | String | 数据来源 | 是 | `WEIGHBRIDGE_XIAOSHAN` |
| `deviceId` | String | 设备编号 | 否 | — |
| `inOutType` | String | 进出类型 | 是 | 进场地：`0`；出场地：`1` |
| `placeType` | String | 场地类型 | 否 | `1` 工地；`2` 消纳场 |
| `goodsWeight` | String | 货物重量 | 是 | — |
| `snapTime` | String | 称重时间 | 是 | — |
| `snapImages` | Array | 附件 | 是 | Base64 格式字符串 |

#### 请求参数示例

```json
{
  "carNo": "浙A6X702",
  "carColor": "绿",
  "carNoColor": "黄",
  "carType": "大车",
  "buildLicenseNo": "330106202212120101",
  "dataSource": "WEIGHBRIDGE_TELECOM",
  "deviceId": "01",
  "inOutType": "0",
  "placeType": "1",
  "snapTime": "2022-06-30 18:27:37",
  "snapImages": [
    "agdasdda24**s83212132rwfadfasdafddawf",
    "agdasdda24**s83212132rwfadfasdafddawf"
  ],
  "goodsWeight": "35000"
}
```

> **注**：原文参数表将 `dataSource` 取值范围写为 `WEIGHBRIDGE_XIAOSHAN`，而示例值为 `WEIGHBRIDGE_TELECOM`。对接时以联调约定为准。

#### Response 参数说明

返回结果示例：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": null
}
```

返回数据类型：`Object`，结构如下：

| 参数名称 | 类型 | 描述 | 取值范围 |
|----------|------|------|----------|
| `code` | code | 状态码 | `200` 成功，其他失败 |
| `msg` | string | 描述信息 | — |
| `data` | object | 信息结构 | — |

### 2.2 地磅心跳接收（间隔 1 分钟）

| 项目 | 说明 |
|------|------|
| **名称** | 地磅心跳接收 |
| **路径地址** | `/sapi/sysdevicemng/heatBeat` |
| **完整示例** | `http://172.18.34.209:8899/sapi/sysdevicemng/heatBeat` |
| **请求方式** | `POST`（`Content-Type: application/json`） |
| **请求公共参数** | 无 |
| **备注** | JSON 请求方式；建议间隔约 1 分钟上报 |
| **路径原文** | 原文路径为 `heatBeat`（非 `heartBeat`），按原文保留 |

#### Request 参数说明

| 参数名称 | 类型 | 参数描述 | 是否必填 | 取值范围 |
|----------|------|----------|----------|----------|
| `buildLicenseNo` | String | 场地标识 | 是 | 地磅安装时由平台运营单位提供 |
| `equipmentNumber` | String | 地磅编号 | 是 | 地磅安装单位提供 |

#### 请求参数示例

```json
{
  "buildLicenseNo": "330106202212120101",
  "equipmentNumber": "DB199"
}
```

#### Response 参数说明

返回结果示例：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": null
}
```

返回数据类型：`Object`，结构如下：

| 参数名称 | 类型 | 描述 | 取值范围 |
|----------|------|------|----------|
| `code` | code | 状态码 | `200` 成功，其他失败 |
| `msg` | string | 描述信息 | — |
| `data` | object | 信息结构 | — |
