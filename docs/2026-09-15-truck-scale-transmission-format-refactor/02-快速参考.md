# 02 — 快速参考

## 设备 × TransmissionFormatType

| ScaleType | tf0 | tf1 |
|-----------|-----|-----|
| Yaohua | 实现（现网连续帧） | **实现**（指令应答） |
| DingSong | 实现（现有 HEX） | 不支持：UI 不可选 + 抛异常 |
| DingSongAddr4 | 实现 | 不支持：UI 不可选 + 抛异常 |
| PortableXPSY | 实现 | 不支持：UI 不可选 + 抛异常 |
| TestMode | 实现（模拟） | **不支持**：UI 不可选 + 抛异常 |

## 关键类型

```csharp
public enum TransmissionFormatType
{
    [Description("(tF0)")]
    TransmissionFormatType0 = 0,

    [Description("(tF1)")]
    TransmissionFormatType1 = 1,
}
```
## 配置（摘要）

| 项 | 约定 |
|----|------|
| 权威 | 仅 `TransmissionFormatType`（默认 `TransmissionFormatType0`） |
| 旧字段 | **停用** `CommunicationMethod`（含 UI）；不读旧值 |
| 设置页通讯方式 | **选择项** → `TransmissionFormatType`；**仅耀华可选 `(tF1)`**，其它 ScaleType（含 TestMode）UI 不让选 tf1 |
| 非耀华 × tf1 | 协议仍实现入口，**抛不支持异常**（禁止假成功） |
| 旧盘 | 忽略旧键 → 默认 tf0 |
| 详文 | [03-旧通讯方式与枚举兼容.md](03-旧通讯方式与枚举兼容.md) |
