# MC 海康威视登录 / 会话生命周期 — 调研总览

- **日期**：2026-09-16
- **范围**：MaterialClient（MC）Urban 客户端海康 LPR / 监控抓拍的 `NET_DVR_Login` 会话管理
- **类型**：代码考古 + 现场证据（探针对照、Wireshark）
- **后续**：建议 OpenSpec change 名候选 `fix-hikvision-session-lifecycle`（未开 change 前本夹为知识落点）

## 结论摘要

1. Urban **Listen + ContinuousShoot 成功**，但常 **收不到** `MessageCallback`；同机独立探针同一 SDK 路径可收到图。
2. 根因不在缺 `SetupAlarmChan` / `SetDVRMessageCallBack_V31`（探针 `arm.enabled=false` 已证 Listen 可收）。
3. Wireshark 见大量 **PC(`192.168.6.200`) → 相机(`192.168.6.100:8000`) TCP RST**，与「短登录 / 测在线立刻 Logout / 多套会话」高度吻合（会话侧；见 `02`/`03`/`04` 与 change `fix-hikvision-session-lifecycle`）。
4. 无摄像头配置时，`6d8a4dcc` soft-reset **不会**触发；有摄像头时 soft-reset 会 `Cleanup` 且 **不重建 LPR Listen**，属设计缺陷。
5. **另根因（2026-09-16 晚复验）**：Urban 已在 `192.168.6.200:9960` LISTENING，但 LPR→PC:9960 仅有 SYN 重传、无 SYN-ACK → **本机入站防火墙丢包**；放行后回传恢复（见 [05](./05-Listen入站9960被防火墙丢弃.md)）。`LISTENING ≠ 入站可达`。
