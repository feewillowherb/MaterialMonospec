# 03 — 修改建议

## 优先级

| 优先级 | 项 | 说明 |
|--------|----|------|
| P0 | 在线检测不要每次真 Login/Logout | **已采纳**：`RemoteControl` + `CHECK_USER_STATUS(20005)`；见 [04](./04-不重复登录校验UserId.md) |

| P0 | 抓拍后无回调超时告警 | Shoot 成功后 N 秒无 `MessageCallback` → Warning（可观测） |
| P1 | 每设备单一长会话 | 启动 Login 一次；抓拍只用缓存；Stop 时 Logout |
| P1 | soft-reset 后重建 LPR Listen + 清 LPR 会话 | 与监控 Cleanup 同事务感知 |
| P2 | 监控与 LPR 共享会话管家 | 同一 `Ip:Port:User` 一个 `userId` |
| P2 | 统一 P/Invoke 入口 | 减少 `HikvisionSdk` / `NET_DVR` 双轨 |
| P3 | 可选自动布防 | 按固件需要；本现场已证非必须 |

## 建议行为（目标态）

```text
启动：
  Init（进程一次）
  → StartListen(9960)
  → 对每个海康 LPR 设备 Login 并缓存 userId
  →（可选）SetupAlarmChan + V31

运行：
  TriggerCapture 仅用缓存 userId + ContinuousShoot
  IsOnline：有缓存且近期探活成功 → 在线；否则 `RemoteControl(CHECK_USER_STATUS=20005)`（见 [04-不重复登录校验UserId.md](./04-不重复登录校验UserId.md)），失败再 Login

停止 / soft-reset：
  CloseAlarm（若有）→ StopListen → Logout 全部 →（soft-reset）Cleanup → Init
  → 再走启动链路重建 Listen / Login
```

## 明确不建议

- 在回调里无差别狂重登。
- 用高频 `IsOnline` 全量 Login/Logout 当健康检查。
- 把「缺布防」当作本现场唯一根因（已被探针否定）。
