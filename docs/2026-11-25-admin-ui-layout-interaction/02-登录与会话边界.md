# 登录与会话边界（Admin × SSO × Redis）

知识状态：源码与 138/135 运行核对为 `CONFIRMED`；「仅改 Redis 即可进 Admin」为 **已否定**。生命周期：`ACTIVE`。

## 1. 两条链路

```text
浏览器 ──POST /login──► Admin (UrbanManagement.Admin)
                           │
                           ├─ 验证码（进程 MemoryStorage，非 135 Redis）
                           └─ SsoWebLoginClient ──POST /GetToken──► SSO 135
                                                      │
                                                      └─ Redis SET FdSoftSSO:{userId}:{clientId}
                           │
                           └─ SignIn ► Cookie UrbanAdmin.Session (HttpOnly)
```

| 层 | 作用 | 证据 |
|----|------|------|
| SSO Redis | GetToken 成功后保存 `LoginUserExtDto` 会话 | `repos/FdSoft.SSO/.../LoginController.cs` `RedisHelper.Set` |
| Admin Cookie | 后续 Blazor 页鉴权；claims 含 userId / product_code / issued_at | `repos/UrbanManagement/src/UrbanManagement.Admin/Sso/AdminSessionCookie.cs` |
| 验证码 | Lazy.Captcha + **MemoryStorage**（显式 Replace，不用分布式缓存） | `repos/UrbanManagement/src/UrbanManagement.Hosting/Captcha/CaptchaRegistration.cs` |

## 3. 「直接改 Redis 登录」边界

| 做法 | 能否进 Admin 业务页 |
|------|---------------------|
| 只 `SET`/`改` `FdSoftSSO:*` | **否** — Admin 不按该键校验每页请求 |
| `GetToken`（副作用写 Redis）+ Admin `/login` SignIn | **是** — 本 Observe Graph 路径 |
| 浏览器 CDP `Network.setCookie` 注入 HttpOnly | **否**（当前 MCP 拒绝）；且伪造 Cookie 需 Data Protection 密钥 |
| 只改 135 Redis 验证码 | **否** — 验证码在 Admin 进程内存 |

结论：Redis 会话是 **SSO 侧**产物；Admin 本地会话是 **Cookie**。Observe / 自动化应写清两步，避免「改 Redis = 已登录 Admin」的误解。
