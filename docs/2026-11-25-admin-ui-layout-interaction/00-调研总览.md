## 结论摘要

1. **壳可用**：侧栏 8 项、顶栏刷新/退出、多标签与白卡片列表页构成一致的信息架构。  
2. **业务页**：城管项目有数据；资源化项目少量；称重/通行/审批在「当日」过滤下多为空态（空态文案可读）。  
3. **交互问题（INFERRED，待产品确认是否改）**：标签与侧栏偶发不同步；分页 `aria-current` 多选；浏览器 `document.title` 与菜单名脱节；窄屏表横向滚动。  
4. **登录边界（CONFIRMED，源码+运行）**：135 `GetToken` 写入 Redis `FdSoftSSO:{userId}:{clientId}`；Admin 鉴权依赖 **HttpOnly** Cookie `UrbanAdmin.Session`。只改 Redis **不能**代替 Admin SignIn。
