# 02 固废：UI / 打印 / Excel 毛皮净对齐（两位小数）

> 先读 [`00-调研总览.md`](00-调研总览.md)。  
> **Human（2026-11-04）**：三位小数显示需求已放弃。新方向是固废**导出与打印**的毛重、皮重、净重与 UI 一致：吨侧先 **保留 2 位小数、四舍五入**（`MidpointRounding.AwayFromZero`，与 `F2` 同口径）。

调研结论已开 OpenSpec：[`openspec/changes/align-solidwaste-weights-ui-f2/`](../../openspec/changes/align-solidwaste-weights-ui-f2/proposal.md)。本夹仍不是产品权威；实现以该 change 为准。

## 1. 目标

| 通道 | 毛 / 皮 / 净应对齐到 |
|------|----------------------|
| 有人值守固废 UI（进场/出场/净重块、详情等） | 吨，`Round(..., 2, AwayFromZero)` 后的显示值 |
| 固废小票打印 | 与上述吨显示一致：先按两位吨再换千克（整数 kg） |
| 固废 Excel 导出（及同源数据管理列表） | 吨列写出与 UI 相同的两位值，而不是库内更长小数 |

库内 `Waybill.OrderTotalWeight` / `OrderTruckWeight` / `OrderGoodsWeight` **不回写**；只改「怎么画 / 怎么导出 / 怎么打票」。

## 2. 权威舍入（Displayed 吨）

与现有 `MaterialMath.ConvertDisplayedTonToKg` 前半段一致：

```text
displayedTon = Round(rawTon, 2, MidpointRounding.AwayFromZero)
printKg      = Round(displayedTon * 1000, 0, MidpointRounding.AwayFromZero)   // 仅打印
excelTon     = displayedTon                                                  // 导出吨列
```

示例（运单库值）：

| 含义 | 库内（吨） | UI / Excel 应对齐 | 小票千克 |
|------|------------|-------------------|----------|
| 毛重 | 13.04 | 13.04 | 13040 |
| 皮重 | 6.045 | **6.05** | **6050** |
| 净重 | 6.995 | **7.00** | **7000** |

注意：两位圆后 **毛 − 皮 可以不等于净**（`13.04 − 6.05 = 6.99 ≠ 7.00`）。本需求明确以「各字段各自对齐 UI」为准，不强求导出/打印上重算净重。

## 3. 现状（2026-11-04 源码）

| 触点 | 路径（相对 Monospec） | 现状 | 与目标 |
|------|------------------------|------|--------|
| UI 毛/皮/净 | `AttendedWeighingViewModel` `F2`；详情 / 手动匹配 AXAML `StringFormat F2` | 两位显示 | 已对齐口径 |
| 打印 DTO | `WeighingMatchingService.CreateWeighingTicketDtoAsync` → `ConvertDisplayedTonToKg` | 先两位再 ×1000 | **已对齐**（`90dfbb71`） |
| 打印绘制 | `TicketPrintingService` `FormatTicketWeightKg` | 整数 kg 字符串 | **已对齐** |
| Excel 行映射 | `SolidWasteService.SolidWasteMapToExportRow` | 直出库内 `Order*Weight` | **未对齐**（如 6.045 / 6.995） |
| Excel 写文件 | `ExcelExportService.RowToValues` / 汇总行 `Sum` | 用行上未圆的吨 | **未对齐** |
| 数据管理网格 | `DataManagementDialogWindow` 绑 `SolidWasteExportRow` 毛/皮/净 | 同源未圆值 | **未对齐**（与 Excel 同源，宜一并处理） |

## 4. 建议改动面（实现时）

优先在**一行映射**收口，避免打印 / Excel / 列表三套舍入：

1. `SolidWasteMapToExportRow`（或 type-owned 投影）对毛/皮/净写 `Round(..., 2, AwayFromZero)` 后再填 `SolidWasteExportRow`。  
2. 汇总行对已圆后的行求和（接受与「先求和再圆」的微小差异；与「所见即所导出」一致时优先对行圆）。  
3. 打印路径已用 `ConvertDisplayedTonToKg`，复核即可；勿再叠第二层 Displayed。  
4. OpenSpec 须改 `solidwaste-excel-export`：毛/皮/净映射从「库内原值」改为「与 UI F2 同口径的两位吨」；补场景（如 6.045 → 6.05）。

**不要动（除非另开需求）**

- 运单 / 称重记录入库精度  
- Urban 上云 `ConvertTonToKg`（未先 Displayed 的路径；与固废打单/导出无关）  
- 超正差 / 超负差 / 计划重量等非毛皮净字段  
- 全站改三位显示（已放弃）

## 5. 验收口径（落地后）

同一固废已完成单：

1. 主界面进场/出场/净重与详情毛/皮/净均为两位。  
2. 小票毛/皮/净千克 = 上述两位吨 ×1000（整数）。  
3. Excel（及数据管理列表）毛/皮/净吨与 UI 数字一致（例：皮 6.05、净 7.00，不是 6.045 / 6.995）。  
4. 库内原始小数仍可在库里查到，未被回写。
