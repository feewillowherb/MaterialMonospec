# 01 毛/皮/净显示：改哪些、不改哪些

> 先读 [`00-调研总览.md`](00-调研总览.md)。  
> **本次只改毛重、皮重、净重怎么显示。超正差/超负差、计划重量、换算率、进库舍入都不动。**

## 1. 算进本次的画面

| 画面 | 对应哪一项 | 现在 |
|------|------------|------|
| 有人值守「进场」 | 收料=毛重，发料=皮重 | `JoinWeightInfo` 两位 |
| 有人值守「出场」 | 收料=皮重，发料=毛重 | `OutWeightInfo` 两位 |
| 固废主界面「净重」 | 净重 | `OffsetBlockValue` 两位（标题已是净重，不要动旁边的偏差文案） |
| 详情「毛重 / 皮重 / 净重」 | 三列 | AXAML 两位 |
| 手动匹配编辑窗毛/皮/净 | 三列 | AXAML 两位 |
| 小票毛/皮/净 | 千克由吨换算 | 先按两位圆再 ×1000，须跟屏幕 |

收料时进场、出场直接用库里的毛、皮，画的时候才收成两位。

## 2. 不要动

| 不要动 | 原因 |
|--------|------|
| 超正差 / 超负差、偏差率、偏差件数 | Human：与本次无关 |
| 计划重量、计划件数、实际件数、换算率 | 不是毛/皮/净 |
| 物料行里的差值、偏差百分比 | 同上 |
| `Waybills` / 称重记录里的数 | 只改怎么画，不回写 |
| Excel 毛/皮/净列 | 已经是库里的小数 |
| 从地磅进库的四舍五入 | 不是界面 |
| 顶部大字「当前重量」 | 默认不在范围；要纳入须另说 |

## 3. 格子

进出场、详情毛/皮/净、固废净重：**够**。  
Urban 列表若展示的是单次过磅重量（相当于毛或皮），列宽 74 像素，三位时略紧，建议加到大约 88–96 像素。

## 4. 本次方案只剩两个

| | A1 毛/皮/净一律三位 | A2 设置里只对这三项选两位或三位 |
|--|---------------------|----------------------------------|
| 库 | 不变 | 不变（设置 JSON 可多一项） |
| 超差 | 不碰 | 不碰 |
| 档位 | **M** | **M～L** |

千克秤进库已是两位吨时，界面画出第三位常常是 0。这是显示问题，不改进库。

## 5. 若动手，看这些就行

- 固废已完成单：进场 13.040、出场 6.045、净重 6.995（不要去验超负差有没有变）  
- 详情三列、手动匹配三列、小票毛/皮/净与屏幕一致  
- Excel 仍是 6.995 不是 7.00  
- 偏差结果、计划重量仍是原样
