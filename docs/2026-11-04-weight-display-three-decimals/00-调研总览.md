# 00 调研总览 — 重量显示与固废毛皮净对齐

> 状态：`ACTIVE`。对照 2026-11-04 源码与运单证据。  
> **三位小数显示（A1/A2）已放弃（Human，2026-11-04）。**  
> **现行方向：** 固废导出与打印的毛重、皮重、净重与 UI 一致——吨侧保留 2 位小数、四舍五入。详见 [`02`](02-固废导出打印对齐UI两位.md)。  
> 这不是 OpenSpec change，不能当授权改代码。

## 1. 现行范围（Human）

| 要做 | 不做 |
|------|------|
| 固废 **UI / 打印 / Excel**（及同源数据管理列表）的毛、皮、净对齐 | 把界面改成三位小数 |
| 吨：`Round(..., 2, AwayFromZero)`（与 `F2` 同口径） | 回写 `Waybill` / 称重记录库值 |
| 打印：两位吨再换整数千克（已有 `ConvertDisplayedTonToKg`） | 超正差 / 超负差 / 计划重量等非毛皮净字段 |
| Excel 吨列写出与 UI 相同的两位值 | Urban 上云单位换算策略（另案） |

库内仍可保留更长小数（例 6.045 / 6.995）；界面、票、表只展示/导出两位圆后结果。

## 2. 那张单（只看毛/皮/净）

| 含义 | 数据库 | UI 现在（F2） | Excel 现在 | 打印现在（kg） |
|------|--------|---------------|------------|----------------|
| 毛重 | 13.04 | 13.04 | 库内原值 | Displayed→kg |
| 皮重 | 6.045 | **6.05** | 仍可能 **6.045** | **6050**（已按 Displayed） |
| 净重 | 6.995 | **7.00** | 仍可能 **6.995** | **7000**（已按 Displayed） |

`13.04 − 6.045 = 6.995`，库内加减无误。两位圆后毛−皮可以不等于净——现行需求接受「各字段对齐 UI」，不重算净重。

## 3. 已放弃：三位显示

| 曾议方案 | 状态 |
|----------|------|
| A1 毛/皮/净一律三位 | **放弃** |
| A2 设置里选两位或三位 | **放弃** |

历史触点清单仍见 [`01`](01-触点清单与UI代价.md)，仅作考古；**不要**再按三位方案开 change。
