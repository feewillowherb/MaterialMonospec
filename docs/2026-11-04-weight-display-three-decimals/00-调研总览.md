# 00 调研总览 — 毛/皮/净显示两位改三位（只改界面）

> 状态：`ACTIVE`。对照 2026-11-04 源码和那张运单。  
> **本次范围已收窄（Human）：只改毛重、皮重、净重怎么画在屏幕上。不动库，不管超正差/超负差。**  
> 这不是 OpenSpec change，不能当授权改代码。

## 1. 范围（以这三条为准）

| 要改 | 不要改 |
|------|--------|
| **毛重、皮重、净重** 的界面显示位数（两位 → 三位，或做成设置里选） | 超正差、超负差、偏差率、偏差件数 |
| 进场/出场格子里的重量（收料时进场=毛重、出场=皮重） | 计划重量、计划件数、实际件数、换算率 |
| 详情和弹窗里标明毛/皮/净的数字 | 运单表、称重记录表里已经存好的数 |
| 固废主界面「净重」那一块 | Excel 导出（本来就是库里的数） |
| 小票上对应的毛/皮/净千克（须和屏幕同一位数，否则票和屏对不上） | 从地磅进库时怎么四舍五入 |

库里那张单仍是 **13.04 / 6.045 / 6.995**。界面现在画成 13.04 / 6.05 / 7.00。改完只是字怎么写，**不重算、不回写**。

顶部大字「当前重量」是秤上正在跳的数，还没分成毛或皮。本次**默认不改**；若司磅时也要看三位，须另说一声。

## 2. 那张单（只看毛/皮/净）

| 含义 | 数据库 | 界面现在 |
|------|--------|----------|
| 毛重（进场） | 13.04 | 13.04 |
| 皮重（出场） | 6.045 | **6.05** |
| 净重 | 6.995 | **7.00** |

`13.04 − 6.045 = 6.995`，库里的加减没有错。

库里同时有超负差、计划重量 7.00，那是另一件事，**本次不做**。

## 3. 本次只在「怎么画字」里选

| 方案 | 做什么 | 库会不会变 |
|------|--------|------------|
| **A1. 毛/皮/净一律三位** | 这三处（及进场/出场、固废净重块）从两位改成三位 | 不会 |
| **A2. 设置里选两位或三位** | 只作用于毛/皮/净显示 | 不会（最多设置 JSON 多一项） |

以前写过的「改偏差计算」「改进秤精度」不在本次。

工作量（Agent token，不是人天）：

| 方案 | 档位 | 大约 token |
|------|------|------------|
| A1 | **M**（比「全站所有重量都改」略小，因为偏差、件数、换算率不动） | 约 15万–40万 |
| A2 | **M～L** | 约 25万–50万 |

格子：有人值守进出场和净重 **够**；Urban 列表若也显示这三档重量、列宽 74 像素，三位时建议加宽。详见 [`01`](01-触点清单与UI代价.md)。
