### Q9 · 车牌 / 图片池（2026-09-08）

| 项 | 约定 |
|----|------|
| 来源 Graph | `pipelines/graphs/materialclient/recycle-wenyixilu-export/`（goal: `recycle-site-db-export`） |
| 输入文件 | `out/latest/csv/WeighingRecords.csv` + `WeighingRecordAttachments.csv` + `AttachmentFiles.csv`（`photoFound=true` 且 `ResolvedPhotoPath` 非空） |
| 池条目 | `{ plate, photoPath, captureClock }`：车牌来自称重行；图来自附件；`captureClock` 优先文件名 `*_yyyyMMdd_HHmmss_*`，否则 `AttachmentFiles.AddDate` / 关联 `WeighingRecords.AddDate` |
| `carNo` / `outPhotos` | **同池同条**抽样（车牌与图绑定）；图读盘转 Base64；优先 `AttachType` ∈ {ExitPhoto=2, Lpr=5} |
| 重量 | **忽略**池内 `TotalWeight`；净/皮/毛仍按 **Q5** |
| 昼夜对齐 | 先定车次 `outTime`（或先抽池再生成时刻，二选一但须同档）；`dayPart(outTime) == dayPart(captureClock)`。`day` = **06:00–18:00**，`night` = 其余。同档内优先 `|H_out − H_cap| ≤ 2` |
| 禁止 | 白天抓拍配夜晚 `outTime`（或相反）；无图条目进池；用池重量覆盖 Q5 |

### Q7 依据（产品代码）

`RecycleTransportRecord.FromWaybill`：`DataNo = waybill.OrderNo`（空则跳过上报，无 `R-{id}` 回退）。

`Waybill.GenerateOrderNo`（Sending / 成品出场）：

```csharp
$"fl-{dateTime:yyyyMMddHHmmss}-{todayCount:D4}"
```

Mock 应对齐：

- 前缀 **`fl-`**（出场销售，非 `sl-` 进场）
- 中间段 = 该车次 `outTime` 的 `yyyyMMddHHmmss`
- 后缀 = **当日**序号 `0001` 起（按 `outTime` 排序后编号）
- 同一 `(outTime 秒级, seq)` 重跑不变 → 与平台 `dataNo` 幂等一致

路径：`repos/MaterialClient/src/MaterialClient.Common/Entities/Waybill.cs`、`.../Recycle/Models/RecycleTransportRecord.cs`。

## 风险（更新）

| 风险 | 缓解 |
|------|------|
| 边界外时刻 | 允许；建议绝大多数落在 06:00–17:30，越界幅度可配置（如 ±30 分钟） |
| 净重/皮重/毛重不在「常见」交集 | 采样时约束 `net∈[19,23]`、`tare∈[13,14.5]`、`gross=net+tare∈[33,37]` |
| 全量车次数（净重变小 → 更多车） | 按 ~21 t 均净重估算全表约 **2.4 万** 车次；分批+限速 |
| `pointNumber` 未齐 | dryRun 验收前禁止 POST |
| Base64 过大 | 池图压 batchSize；可对出图做 JPEG 再压缩 |
| 昼夜错配（图白天 / 点夜晚） | **Q9**：按 `dayPart` 分桶抽样；验收抽查 `captureClock` vs `outTime` |
| 池图缺失（export missing≈298） | 仅用 `photoFound=true`；池耗尽则复用同档条目（仍绑原车牌） |
