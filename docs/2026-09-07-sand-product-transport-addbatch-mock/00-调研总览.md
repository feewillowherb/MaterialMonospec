# 00 · 调研总览：月汇总吨位 → §2.2 addBatch 按天按时 Mock 提交

## 背景

业务侧提供 `_tmp/data.md`：5 家收货公司 × 2026 年 1–5 月 **成品销售吨位**月汇总（合计约 **518,065.31 吨**；表曾标「沙加石」，现按车次拆为两种产品）。需将其还原为市平台「成品销售车次」粒度数据，调用：

```http
POST /dataCenter/resourcePlace/productTransportRecord/v1/addBatch
```

（文档：[杭州市资源化利用厂数据接入接口 V1.0 §2.2](../SyncDoc/杭州市资源化利用厂数据接入接口V1.0.md)；客户端契约见 `repos/MaterialClient/.../IRecycleDataApi.cs`。）

月表只有「谁 × 哪月 × 多少吨」，缺少车次、车牌、出场时刻、照片等；本方案约定 **按天 → 按时（车次）拆分**，并 **Mock 其余必填/常用字段**，使总量守恒、时间分布可解释、可批量 HMAC 上报。

## 目标

| 项 | 说明 |
|----|------|
| 输入 | `_tmp/data.md`（或等价 CSV/YAML） |
| 输出 | 若干批 JSON Array，每元素符合 §2.2 Request |
| 守恒 | 每「收货公司 × 月」的 `Σ netWeight` **等于**月表吨位（误差 ≤ 0.01 吨，由末车次兜底） |
| 时间 | 每条记录有唯一合理 `outTime`（精确到秒；按天、再落在营业小时内） |
| 鉴权 | 与现网一致：`X-AKZTJG-*` HMAC（附录 1） |

## 非目标

- 不改 MaterialClient / 市平台生产代码（本夹为 **运维/脚本方案**；若要产品化再走 OpenSpec）
- 不保证市平台侧「业务真实性」审计通过（明确为 **补数 / 联调 / 演示 Mock**）
- 不覆盖 §2.3 `materialTransportRecord`（进场物料）
- 不在本夹存放真实 AccessKey / Secret / 实拍 Base64

## 推荐结论（摘要）— Q1–Q11 已锁定

1. **年份 / 日历**：2026；**任意日**（含周末）为候选；`outTime` 主窗口 **06:00–17:30**，**允许**少量落在边界外。
2. **产品（Q4）**：`productName` 仅为 **`再生细骨料`** / **`再生粉料`**，车次 **1:1**；收货公司名 → **`consignee`**。
3. **车载**：净重 19–23 t，皮重 13–14.5 t，毛重 = 净+皮且落在 33–37 t（**不读现场池重量**）。
4. **dataNo**：`fl-{pointNumber小写}-{yyyyMMddHHmmss}-{今日序号:D4}`（例 `fl-xnyh20251113001-20260101061339-0001`）；基于 Recycle Sending 的 `fl-` 形态并插入场地标识；**必须持久化**；平台按 `dataNo` 幂等，后续可同键更新（Q7）。
5. **收货完成字段**：地址见 [06](./06-收货方到货地址.md)；**`receivingTime` = `outTime` + 1.5h～2.5h（Q10）**；首次是否写入见 Q6，补报时必填地址与收货时间。
6. **pointNumber / HMAC**：dryRun 验收通过后由用户输入再真实 POST（Q3）。
7. **落地规模**：M（约 15万–40万 token）；全表约 **2.4 万** 车次量级（按 ~21 t/车）。
8. **车牌/图（Q9）**：用 `recycle-wenyixilu-export` CSV 池；`outTime` 昼夜与抓拍元数据同档。
9. **活跃度（Q11）**：五家活跃日占比档位互异；每月抽 **2～4** 个周末日全场低/零活跃；**不是**每家每天都有货。

明细见 [04-开放问题与落地规模.md](./04-开放问题与落地规模.md)。
