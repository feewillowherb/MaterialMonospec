# 02 · 按天按时拆分算法

目标：对每个 `(consignee, year, month)` 的月吨位 `T`，生成车次集合 `R`，满足：

1. `Σ r.netWeight = T`（绝对误差 ≤ `ε`，默认 `0.01`）
2. 每个 `r.outTime` 落在该月合法日内、营业小时内（Q2）
3. 同日多车次分布在不同小时（或同小时不同分钟），避免全部挤在 `00:00:00`
4. `carNo`/`outPhotos` 来自文一西路池，且 `dayPart(outTime)==dayPart(captureClock)`（Q9）；重量不读池
5. `productName` ∈ {再生细骨料, 再生粉料}，同 consignee×月车次 **1:1**（Q4）

## 1. 参数（建议配置化）

| 参数 | **已锁定** | 含义 |
|------|----------|------|
| `year` | `2026` | 月表年份（Q1） |
| `workCalendar` | `all-days` | 任意日历日含周末（Q2）；**非**「每天每家必有车」 |
| `businessHours` | `06:00–17:30` | 出场主窗口（Q2） |
| `businessHoursSoftMargin` | 允许边界外 | 少量车次可略早于 06:00 或略晚于 17:30（Q2） |
| `tripNetMin` / `tripNetMax` | `19` / `23` | 砂石净重吨（Q5） |
| `tareMin` / `tareMax` | `13` / `14.5` | 皮重吨（Q5） |
| `grossMin` / `grossMax` | `33` / `37` | 毛重目标区间；须 `gross≈net+tare`（Q5） |
| `seed` | 固定整数 | 随机可复现；公司画像用 `seed ⊕ hash(consignee)` |
| `ε` | `0.01` | 月末吨位兜底精度 |
| `quietWeekendCount` | `2～4` | 每月从周末中抽 **2～4** 天：全场 **0** 或 **低活跃**（Q11） |
| `companyActiveDayRates` | 拉开档位 | 五家 **不得** 用同一活跃日占比（Q11） |
| 车牌/图池 | **Q9** | `recycle-wenyixilu-export` CSV；昼夜同档；**重量不读池** |

## 2. 流水线

```text
月吨位 T
  │
  ▼
① 枚举可出场日 D[]（工作日/全月）
  │
  ▼
② 日权重 w_d → 日目标吨 t_d（Σ t_d = T）
  │
  ▼
③ 对每个 t_d：切成车次净重列表 n_1..n_k（Σ n_i = t_d）
  │
  ▼
④ 将 k 车次映射到营业小时：hour_slot + 分钟抖动 → outTime
  │
  ▼
④b 按 outTime 的 dayPart 从文一西路池抽 {plate, photo}（Q9；重量仍 Q5）
  │
  ▼
④c 按 outTime 排序后交替赋 productName：再生细骨料 / 再生粉料（Q4 · 1:1）
  │
  ▼
⑤ 填充 Mock 字段 → Record
```

> **Q9**：`dayPart`：`day` = 06:00–18:00，`night` = 其余。池条目的 `captureClock` 须与 `outTime` 同档；同档内优先小时差 ≤ 2。主窗口 06:00–17:30 几乎全落在 `day`，边界外略晚（如 17:31–17:45）仍属 `day`；若将来有深夜越界，必须配 `night` 池图。

### ① 可出场日

- **全部日历日**（Q2）：该月 1…lastDay，含周末。
- 2 月天数少 → 单日吨位更高。

### ② 月 → 日（稀疏活跃日 + 公司画像 + 安静周末 · Q11）

**禁止**「每家每天都有、曲线几乎同形」。流程：

```text
① 枚举该月周末日 W[]（周六/日）
② 抽 quietWeekendCount ∈ [2,4] 天 ⊂ W
   对每个安静周末：mode ∈ {zero, low}（约各半）
   - zero → 全场该日权重 = 0（无车）
   - low  → 全场该日权重 ≈ lowFactor·(1+抖动)，lowFactor 默认 0.08
③ 为每家 consignee 分配互不相同的 activeDayRate（拉开档位，如 ~0.40 / 0.52 / 0.65 / 0.78 / 0.90）
   另可配 weekdayBias / burstiness，避免五家开/停日重叠过高
④ 对「非 zero 安静日」的候选日：按该公司 activeDayRate 抽样是否活跃
   活跃日 raw_d = 1 + U(-δ, δ)；非活跃 = 0；low 安静日用低权重
⑤ 若活跃权重全 0 且 T>0：强制挑 1 个非 zero 日兜底
⑥ t_d = T * raw_d / Σ raw；round(2)；末活跃日吃掉舍入误差
```

约束摘要：

| 约束 | 要求 |
|------|------|
| 公司活跃度差异 | 五家 `activeDayRate` **档位互异**；公司专属 RNG，发货日集合不可近似全覆盖且彼此雷同 |
| 安静周末 | 每月 **2～4** 个周末日全场低/零活跃；其余周末仍可按公司画像发货 |
| 守恒 | 仍保证 `Σ t_d = T`（仅摊在权重 > 0 的日） |

### ③ 日 → 车次（净/皮/毛自洽）

单车采样（拒绝采样直到落入区间）：

```text
repeat:
  net  ~ U(19, 23)
  tare ~ U(13, 14.5)
  gross = round(net + tare, 2)
until gross ∈ [33, 37]
```

切日吨位：

```text
while remain > tripNetMax:
    sample (net, tare, gross) as above
    net = min(net, remain)  # 末段可截断；截断后重算 gross=net+tare（可放宽 gross 上界校验）
    emit; remain -= net
if remain > 0:
    emit 末车 net=remain（tare 仍采样；gross=net+tare，允许略出 33–37）
```

车次数：`k ≈ ceil(t_d / 21)`。

### ④ 车次 → 时刻（主窗口 06:00–17:30，允许越界）

小时桶：主分布在 **06:00～17:30**（含 6～16 点整点小时，以及 17:00–17:30 半段）。

```text
将 k 车次按权重摊到营业小时（中午可略低、早晚可略高，可选）
分钟/秒：抖动；同小时内错开
约 p%（建议 5%～10%）车次：outTime 落在窗口外
  - 略早：05:45～05:59
  - 略晚：17:31～17:45
  （幅度可配置，避免散落到深夜）
```

`outTime = f"{year}-{month:02}-{day:02} {HH}:{mm}:{ss}"`

「按时」= 绝大多数落在 **06:00–17:30**，允许少量边界外；不是日汇总一条。

### ⑤ 守恒校验（每收货公司每月）

```text
assert abs(Σ netWeight - T) <= ε
assert 所有 outTime 落在该月
assert 无重复 dataNo
```

## 4. 伪代码（单收货公司单月）

```python
def expand_month(consignee, year, month, T, cfg, rng, quiet_weekends, profile):
    days = list_calendar_days(year, month)  # all-days 候选
    day_tons = allocate_day_tons(T, days, profile, quiet_weekends, rng, eps=cfg.eps)
    records = []
    for day, t_d in zip(days, day_tons):
        if t_d <= 0:
            continue
        nets = split_trips(t_d, cfg.trip_min, cfg.trip_max, rng)
        times = assign_out_times(day, len(nets), cfg.hours, rng)
        for net, out_time in zip(nets, times):
            records.append(build_record(consignee, net, out_time, cfg, rng))
    assert abs(sum(r["netWeight"] for r in records) - T) <= cfg.eps
    return records
```

## 5. 不推荐的做法

| 做法 | 原因 |
|------|------|
| 一月一条、净重=月合计 | 不符合「车次」语义，易被平台拒或失真 |
| 只按天不按小时（全日同一 `outTime`） | 违背「按时」；易撞唯一性/风控 |
| 五家同一 `activeDayRate` / 全月每天都有 | 违背 Q11；行为过于相似 |
| 净重用 kg 再当吨上传 | 数量级错 1000 倍 |
| 无 seed 的纯随机 | 无法复现、无法对账重跑 |
