## 2. 目标接口 §2.2

| 项 | 值 |
|----|-----|
| Path | `/dataCenter/resourcePlace/productTransportRecord/v1/addBatch` |
| Method | `POST` |
| Body | JSON **Array** |
| Auth | Header `X-AKZTJG-*` HMAC-SHA256（附录 1） |
| 成功 | `code == 200` |

权威字段表见 [SyncDoc §2.2](../SyncDoc/杭州市资源化利用厂数据接入接口V1.0.md)。产品侧 Refit：`IRecycleDataApi.SubmitTransportRecordAsync`。

### 必填（文档）

| 字段 | 本方案来源 |
|------|------------|
| `dataNo` | `fl-{outTime:yyyyMMddHHmmss}-{日序:D4}`（对齐 `Waybill.OrderNo` / Sending） |
| `pointNumber` | dryRun 占位；真实提交前用户输入（Q3） |
| `carNo` | Mock 车牌池 |
| `productName` | 固定 `沙加石`（Q4） |
| `netWeight` | 19–23 t（Q5） |
| `outTime` | 2026 任意日；主窗口 06:00–17:30，允许边界外（Q1/Q2） |
| `outPhotos` | Mock：夹具图 Base64（无 Data URL 头） |

### 可选一并 Mock

| 字段 | 规则摘要 |
|------|----------|
| `dataStatus` | 固定 `0` |
| `tareWeight` / `grossWeight` | 皮 13–14.5；毛=净+皮 ∈ 33–37（Q5） |
| `consignee` | 月表「名称」= **收货公司**（Q8） |
| `carrierCompanyName` | 可选 |
| `consigneeAddress` / `receivingTime` / `receivingProof` / `saleContractNo` / `unitPrice` / `payAmount` | **不传**（Q6） |

## 3. 单位与语义

| 概念 | 约定 |
|------|------|
| 月表、接口 `netWeight` | **吨** |
| 车载（Q5） | 净 19–23；皮 13–14.5；毛 33–37（=净+皮） |
| 勿混用 | Mock **直接用吨**，禁止再 ÷1000 |

## 4. 业务语义（已锁定）

```text
资源化利用厂（pointNumber，用户后补）──销售/出场──► 表中收货公司（consignee）
                    产品 = 沙加石（强制）
                    dataNo = fl-{outTime}-{日序}（幂等）
```
