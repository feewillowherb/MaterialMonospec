# 01 · 范围与不变量

## 范围内

- 仅 **MaterialClient.Urban**（及 Urban 产品 Common / `UrbanDbContext`）。
- 卡口数据与成品数据 **同一实体**，用 **来源类型** 区分（来自卡口 / 来自成品），不要两张同构表。
- 无重量列；不走内核 `WeighingRecord` / `UrbanWeighingExtension`。
- 由 **LPR 卡口、LPR 成品** 识别创建（配置行 `LprSiteType` 为 `Checkpoint` / `FinishedProduct`）。
- Urban 客户端：**全部记录** + **卡口** + **成品** 两个新 tab。

## 范围外（除非后续 change 写明）

- 标准 / 固废 / 回收宿主。
- 地磅 LPR（`LprSiteType.Scale`）仍走现有称重。
- 地磅上报 `lantu/saveRecord`（必填 `goodsWeight`）。
- 把萧山 JSON 字段名原样当 C# 属性。
- **任何上传**（萧山 `inoutRecord/save`、地磅上云、政务同步扩展）。

## 不变量

| 项 | 约定 |
|----|------|
| 表归属 | `UrbanDbContext`，独立 Urban migration history |
| 附件 | 有则入库、无则不补；不强制两张、不复制凑数。不进实体大字段；逻辑 Id，**禁止库 FK** |
| 默认值 | 颜色缺省「无」；车型缺省「大车」 |
| 进出 | 实体字段名 **`UrbanInOutType`**，复用已有枚举 `Enter` / `Exit` |
| 场地性质 | 实体字段名 **`UrbanSiteType`**，复用已有枚举 `Construction` / `Disposal`（工地/消纳） |
| LPR 点位 | **`LprSiteType`**：地磅/卡口/成品。与 `UrbanSiteType` **不是同一概念** |
| 创建快照 | 行上的 `UrbanSiteType` / `UrbanInOutType` 在创建时写入，避免事后改设置改写历史 |

## 与 `add-lpr-site-type` 的关系

该 change 规定站点类型 **暂无运行时语义**。本功能一旦落地，卡口/成品识别 **必须** 按 `LprSiteType` 分支创建进出记录；地磅行仍不得走本实体。实现时在 OpenSpec 里 **修改** `lpr-site-type` 能力，不要 silently 违背旧 delta。
