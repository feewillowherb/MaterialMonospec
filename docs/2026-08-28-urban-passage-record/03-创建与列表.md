# 03 · 创建与列表

## 创建

1. LPR 识别到达（现有 MessageBus / 设备回调）。  
2. 用识别到的设备匹配配置行，读 **`LprSiteType`**。  
3. `Scale`：现有称重，不写本实体。  
4. `Checkpoint` / `FinishedProduct`：写入 `UrbanPassageRecord`（`PassageSource` 对应），**有图则存、无则不补**，**不** `CreateWeighingRecord`。  
5. `UrbanInOutType`：由该行进出方向（进场/出场）映射 `Enter`/`Exit`。  
6. `UrbanSiteType`：从当时萧山/城管设置快照。  
7. `PlateColor` / `VehicleType`：识别结果有则用；否则「无」/「大车」。

数据访问：ViewModel → Urban Service → Urban Repository → `UrbanDbContext`。Service 写操作 `[UnitOfWork]`。同库双 Context 规则见 [`../2026-08-28-materialclient-product-ef-isolation/`](../2026-08-28-materialclient-product-ef-isolation/00-调研总览.md)。
