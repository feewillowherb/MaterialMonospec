# 05 · 列表列设计（全部混合 vs 专用 tab）

**日期**：2026-08-28

「全部记录」采用 **一张混合表**（称重 + 卡口 + 成品按时间交错）。右侧照片 **只放大图**：海康两张里取大图；没有大图则空位，**不展示小图**。卡口 / 成品专用 tab **只出进出业务列**，不复制称重列。

车牌展示：库内未识别仍为「无」；**列表车牌列显示「未识别」**，不原样显示「无」。颜色列的「无」可以原样显示。

## 行类型

混合表每行带 `Kind`：`Weighing` / `Checkpoint` / `FinishedProduct`。操作列按 Kind 分叉：称重保留现网「审批」；进出本期 **不要审批**（无上云、无异常流）。

## 全部记录（混合）

从左到右建议列。称重缺的进出字段、进出缺的称重字段用「—」，不要藏列。

| 列（UI） | 称重行 | 进出行（卡口/成品） |
|----------|--------|---------------------|
| 类型 | 地磅 | 卡口 / 成品 |
| 车牌 | 现网车牌；空按现网异常文案 | 「无」→ **未识别** |
| 重量 | 现网重量列（单位与现网一致） | — |
| 进出 | 若现网有进出/方向则显示，否则 — | `UrbanInOutType`：进 / 出 |
| 时间 | 称重时间 | `CapturedAt` |
| 状态 | 现网正常/异常徽章 | —（不要套 `IsAnomaly`） |
| 操作 | 现网审批 | 空，或仅「查看」（本期可不做） |
| 照片（右） | **仅大图**（车牌识别大图优先；无则空） | **仅大图**（两张中的大图；无则空） |

**不要**出现在全部表：车牌颜色、车型、`UrbanSiteType`、小图。避免和称重列抢宽度。

分页：两源按时间 merge 后分页（实现细节 OpenSpec design）。正常/异常 tab **仍只称重**，不过滤进出行。

## 卡口 tab / 成品 tab（专用）

两 tab **列相同**，仅 `PassageSource` 过滤不同。不要重量、异常、审批、类型列（tab 已表达来源）。

| 列（UI） | 绑定 |
|----------|------|
| 车牌 | 「无」→ **未识别** |
| 车牌颜色 | `PlateColor`（可显示「无」） |
| 车型 | `VehicleType`（可显示「大车」） |
| 进出 | `UrbanInOutType` |
| 场地 | `UrbanSiteType`（工地/消纳） |
| 抓拍时间 | `CapturedAt` |
| 照片（右） | **仅大图**；小图不展示 |

## 大图约定

入库仍可 0～2 张。UI 只取 **大图槽**（海康成对时的第一张/大图；仅一张时就用这一张）。专用 tab 与全部表规则相同。
