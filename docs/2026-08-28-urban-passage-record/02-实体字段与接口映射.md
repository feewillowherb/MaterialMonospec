# 02 · 实体字段与接口映射

接口权威：[场地进出 `inoutRecord/save`](../SyncDoc/杭州市工程渣土监管服务平台场地数据接口（萧山）V1.0.md)。本表只列 **进实体的、必填且非静态** 的业务列；C# 用项目命名。

工作名：**`UrbanPassageRecord`**（实现时可改，避免 `*Weighing*`）。

## 来源类型（本实体自有，不是萧山 `siteType`）

| 项目 | 含义 |
|------|------|
| 建议属性 | `PassageSource`（或同等命名） |
| 值 | 卡口 / 成品，对应 `LprSiteType.Checkpoint` / `FinishedProduct` |
| 不要 | 塞进 `UrbanSiteType` |

## 落库列（接口 → 项目）

| 萧山 Request | 项目属性 | 说明 |
|--------------|----------|------|
| `carNo` | `PlateNumber` | 未识别与文档一致可存「无」 |
| `carNoColor` | `PlateColor` | SDK 无则默认「无」 |
| `carType` | `VehicleType` | SDK 无则默认「大车」 |
| `snapTime` | `CapturedAt` | `DateTime` |
| `snapImages` | （附件关联） | 有则入库、无则不存；不凑第二张。本期不上报，不组 Base64 |
| `deviceID`（`01` 进 / `02` 出） | **`UrbanInOutType`** | 已有 `Enter=0` / `Exit=1`；以后上报再映射 `01`/`02` |
| `siteType`（`1` 工地 / `2` 消纳） | **`UrbanSiteType`** | 已有 `Construction` / `Disposal`；创建时从萧山设置快照 |

**不要**用 `DeviceCode` 表示进出。

## 不进本实体（静态或可选）

上报或设置层处理，**本期不实现上报**，也不作为本记录必填列：

| 萧山 | 原因 |
|------|------|
| `buildLicenseNo` | 静态；成品 `-02` 规则见 `xiaoshan-upload-field-mapping` |
| `areaCode` | 静态 |
| `spaceName` | 可选 + 静态 |
| `carColor` | 可选，本期不要求 |
| `goodsWeight` | 可选；本实体无重量 |

## 已有枚举（勿平行再造）

`repos/MaterialClient/src/MaterialClient.Common/Entities/Enums/XiaoshanUploadEnums.cs`：

- `UrbanInOutType`：`Enter` / `Exit`
- `UrbanSiteType`：`Construction` / `Disposal`
