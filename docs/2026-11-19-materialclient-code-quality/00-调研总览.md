## 可复查范围

- 用 `git ls-files 'src/*.cs'` 选择纳入 Git 的源码，排除 Migrations 后按 PowerShell 读取的物理行数排序。行数包含注释和空行。
- 用 `rg -l 'IRepository<|DbContext' src -g '*ViewModel.cs'` 筛选候选，再手动核对解析和调用路径。此扫描可能漏掉非标准命名的界面类或间接访问。
- 已抽查 `WeighingCycleIsolationTests`、`WeighingStableWeightCarryoverReproductionTests` 和 `WeighingFailureRecoveryInvestigationTests` 的用例文件存在性。 [Common 测试目录](../../repos/MaterialClient/tests/MaterialClient.Common.Tests/Tests)
- UNKNOWN：整体代码覆盖率、现场设备环境中的时序表现、Urban 开机和前台保持行为。本次未连接现场设备。

### 复跑定位

同一提交上额外全量复跑四次，三次通过，一次捕获 `HikvisionLprServiceMemoryLeakTests.DeviceConfigManagement_ShouldNotLeakMemory` 失败。断言要求托管堆增量小于 1,000,000 字节，失败时报告 1,136 KB。隔离复跑该用例三次均通过。

用例对 Mock 服务重复添加和更新 1,000 个配置，前后读取 `GC.GetTotalMemory(true)`。该指标包含整个测试进程的托管堆，也包含用例保留的配置，其他用例分配可能影响差值。已确认断言偶发失败，尚未证实生产服务泄漏或首次失败为同一用例。 [断言](../../repos/MaterialClient/tests/MaterialClient.Common.Tests/Tests/HikvisionLprServiceMemoryLeakTests.cs#L309)
