## 2. 全站 4 个核心复用组件（直击 R1 / R2 / R3）

### 2.1 `OpsDataTable`（落地 R2）
- 基于 `el-table` 开启 `border`、`height="100%"`（吸顶表头 + 横纵独立滚动）。
- **所有列默认 `resizable: true`**，用户拖动任意表头右边缘即可调整宽度。
- 监听 `header-dragend` 事件，按 `tableKey` 将列宽存入 `localStorage`；底栏提供轻量「重置列宽」按钮，恢复默认最优列宽。

### 2.2 `InlinePhotoPair`（落地 R1 + D1）
- 在表格单列「现场照片」中并排展示 **2 张缩略图**（每张 `72×48px`，`border-radius: 4px`，`object-fit: cover`，间距 `6px`）。
- 基于 `el-image` 开启 `lazy` 懒加载、`preview-teleported`、`preview-src-list`（传入该行有效图片 URL 数组）：
  - **扫读态**：无需弹窗即可直接看清两张现场图；
  - **详情态**：点击任意缩略图即刻全屏灯箱放大，支持缩放、旋转、左右键切换 2 张图；
  - **缺图/失败态**：显示与缩略图等大的浅灰虚线占位框（「无图」或具体缺失提示），不出现裂图图标。

### 2.3 `ProjectRemoteSelect`（落地 R3）
- 彻底替代旧手写 `.searchable-select`，基于 `el-select`（`filterable`、`clearable`）定制：
  - **宽弹层解耦**：`popper-class="project-select-popper"` 设置 `min-width: 520px; max-width: 680px`（窄屏按 `90vw` 自适应），不再受限于触发器宽度；
  - **选项完整换行**：下拉选项取消 `white-space: nowrap` 与省略号，允许 2–3 行完整展示项目全称（次行弱灰展示对接码，便于同名/近名区分）；
  - **触发器优化**：输入框宽度 `240px–280px`，选中长名称后 hover 自动弹出 `el-tooltip` 显示完整名称。

### 2.4 `DateRangeShortcuts` + URL Query 同步
- 基于 `el-date-picker`（`type="datetimerange"`），内置快捷区间：**今日 / 近 3 天 / 近 7 天 / 本月**。
- 所有列表页的筛选条件（状态、关键词、项目、车牌、时间区间、页码）双向同步到 URL Query，刷新不丢状态、复制 URL 可直接发给同事排查同一批数据。
