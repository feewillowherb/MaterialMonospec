# 四页、匿名拒绝与快照 FEV

知识状态：`PENDING_VALIDATION`。这一轮只判断下面四个问题是否可行，不是 Capability 交付。

## 问题

1. 浏览器里车辆、合同、日产量、运输清单能否新增或查到已保存的行，刷新后还在？车辆 1234.5 kg 是否显示为 1.2345 t？
2. 非 Testing 环境下，没有 `Recycle.Session` 的业务请求是否返回 401？请求体里的项目标识能否改变归属？
3. 合同、日产量、运输清单页面是否已经用 Guid，并且重量输入不再被固定小数位截断？
4. 跨项目写入是否被拒绝？小数位超限是否被拒绝？修改或软删除车辆后，已有运输清单的皮重快照是否保持不变？

## 实验

- 浏览器走 `http://127.0.0.1:5341`，环境为 Testing，所以页面不要求登录。
- 匿名检查另起一个 Development 进程，只用来打 401 和登录跳转，测完即停。绑定仍是 `50200000-0000-4000-8000-000000000020`。
- 数据库是本机 LocalDB `UrbanManagement`。

## 证据

| 问题 | 观察 |
|------|------|
| 车辆新增 | 对话框录入 `FEVWEB01`、皮重 1234.5 kg。表上立即显示 1.2345。刷新后仍在 |
| 车辆归属 | 另一次请求带了别的 `sourceProId`。`PROBODY` 的 `ProId` 仍是绑定的 5020 标识 |
| 合同新增 | 浏览器保存 `FEV-WEB2`，数量 1.5 吨、单价 2。明细 `QuantityKg=1500`，`Amount=3000.00`。页面金额显示 3 |
| 合同精确数量 | 同一对话框先提交数量 1.2345 吨。接口 HTTP 400，`RECYCLE:DECIMAL_SCALE`，金额小数位超过 2。该行没有写入 |
| 日产量 | 页面没有新增按钮。接口写入 1.2345 吨后，页面单元格显示 1.2345，合计行显示 1.23。刷新后 `FEVPROD` 仍在 |
| 运输清单 | 已有行显示 `2.5 / 1.2345 / 1.2655`。过磅框把输入的 1.2345 收成 1.23。随后以 `FEVWEB01`、毛重 2.50 生成清单，库中毛重 2500 kg、皮重 1234.5 kg、净重 1265.5 kg。刷新后两行都在 |
| 匿名 | Development 上 `GET /api/vehicles` 与带项目标识的 `POST /api/vehicles` 都是 HTTP 401，没有 `NOAUTH` 行。打开 `/` 得到 302，位置是 `/login?returnUrl=%2F` |
| 小数位 | 车辆皮重 `1.1234567891` 返回 HTTP 400，`RECYCLE:DECIMAL_SCALE` |
| 跨项目 | 另一 `ProId` 的运输清单存在于库中。对它 `PUT /api/transports/{id}` 返回 HTTP 400，`RECYCLE:NOT_FOUND`。列表里没有 `OTHER01`，该行 `ContractNo` 仍为空 |
| 快照 | 把 `ZHEAFEV01` 皮重改为 2000 kg，再软删除该车。运输清单 `87ab1e31-5fe9-4e56-ba45-4810b124a40d` 仍是皮重 1234.5 kg、净重 1265.5 kg |

## Verdict

1. `FEASIBLE`。四页都能读到已保存的行，刷新后还在。车辆页能新增，1234.5 kg 显示为 1.2345 t。合同页能新增可被接受的数量。日产量页本身没有新增入口。运输清单页能过磅生成新行。
2. `FEASIBLE`。非 Testing 的匿名业务请求返回 401，页面会去登录。请求体里的项目标识不改变 `ProId`。这次没有做真实的 5041 登录。
3. `INFEASIBLE`。这三页还不能当作已经改成精确公斤输入。过磅毛重会把 1.2345 收成 1.23。日产量合计用两位小数，1.2345 显示成 1.23。合同页金额按吨乘单价后四舍五入，1.2345 吨乘单价 2 被服务端拒绝，页面只提示保存失败。
4. `FEASIBLE`。跨项目更新被拒绝，超限小数被拒绝，车辆修改和软删除没有改写已有运输清单的皮重与净重。

`ZHEAFEV01` 这辆实验车在快照实验后处于软删除状态。对应运输清单还在。
