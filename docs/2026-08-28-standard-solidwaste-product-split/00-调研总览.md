## 一句话

**凡东智能物料验收**（`WeighingMode.Standard`）和 **城管固废称重验收**（`WeighingMode.SolidWaste`）今天挤在同一个 WinExe（`MaterialClient`）和同一套 `AttendedWeighing` 里；后续应像 Urban / Recycle 一样拆成 **产品 Common + 独立客户端**，内核表继续冻结。

## 产品名 → 代码（先认准，避免和 Urban 搞混）

| 对外名称（枚举 Description） | 代码 | 今日形态 |
|------------------------------|------|----------|
| 凡东智能物料验收系统V2.0 | `WeighingMode.Standard` / `ProductCode.Standard` (5000) | `MaterialClient.exe` 主路径；安装脚本 `MaterialClient.iss` 显示名仍是 `MaterialClient` |
| 城管固废称重验收系统客户端软件 | `WeighingMode.SolidWaste` / `ProductCode.SolidWaste` (5010) | **同一** `MaterialClient.exe` 内切模式；无独立 WinExe |
| 城管地磅称重系统客户端软件 | `ProductCode.Urban` (5001) / `WeighingMode.UrbanMode` | 已拆：`MaterialClient.Urban` + `Common.Urban` |
| 资源化利用厂称重系统客户端软件 | `ProductCode.Recycle` (5020) | 已拆：`MaterialClient.Recycle` + `Common.Recycle` |

注意：`WeighingMode.UrbanMode` 的 Description **误写成**与 SolidWaste 相同的「城管固废称重验收…」。分离固废时不要把 Urban 地磅端当成固废客户端。
