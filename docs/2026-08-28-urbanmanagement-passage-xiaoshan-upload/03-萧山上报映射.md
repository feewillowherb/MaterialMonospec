# 03 · 萧山上报映射

协议细节以设计稿为准，此处只写 **UrbanManagement 出站** 怎么选 Client、怎么填字段。

## 通道选择

| 源 | HTTP | `buildLicenseNo` |
|----|------|------------------|
| `UrbanWeighingRecord` | `POST /sapi/v1/inoutRecord/lantu/saveRecord` | 原值 `L` |
| 进出 + `Checkpoint` | `POST /sapi/v1/inoutRecord/save` | 原值 `L` |
| 进出 + `FinishedProduct` | 同上 | `XiaoshanBuildLicenseNo.ForProduct(L)` |

`L` 来自项目/场地配置（现网称重行上的 `BuildLicenseNo`）。进出行若不存 `L`，从 **同一项目** 配置读取，变换只做一次。平台凭有无 `-02` 区分成品/卡口（Q2）。

地磅、卡口、成品 **三条出站代码独立**（payload `record`、Converter、Worker 调用各写一套，允许重复）。不要共用一个「场地 save + 后缀参数」。URL 上卡口与成品相同 **不能** 合并实现。Refit **BaseAddress 只读 UM 独立配置的 Gov host**（Q5）。地磅 builder **不得**写入卡口字段集，卡口/成品 builder **不得**写 `dataSource`。

## `UrbanWeighingRecord` → 地磅（摘录）

权威：地磅 SyncDoc + 设计稿 §3。现网 `GovSyncWeightPayload` **混有** `inOutType` 与 `deviceID`/`siteType`/`areaCode`，且 `IGovSyncHttpClient` 为 `[Post("")]`（基址即完整 URL）。落地时地磅报文应对齐 `lantu/saveRecord`：`dataSource` **恒为** `WEIGHBRIDGE_XIAOSHAN`，`inOutType` / 卡口侧 `deviceID` 经 **Converter**（见下），`goodsWeight` 必填。不要继续用卡口 schema 冒充地磅。

重量：本地吨 vs 上云千克见 `repos/MaterialClient/AGENTS.md`；服务端已按 kg 存的保持一致。

## 出站 Converter（Q4）

仅在 UrbanManagement **组 Gov 报文时**调用，不在来自 LPR 卡口/成品的落库路径上改码。

| 领域 | 地磅报文 | 卡口/成品报文 |
|------|----------|----------------|
| `UrbanInOutType.Enter` | `inOutType` = `0` | `deviceID` = `01` |
| `UrbanInOutType.Exit` | `inOutType` = `1` | `deviceID` = `02` |
| `UrbanSiteType.Construction` | （地磅若有同类字段则同转） | `siteType` = `1` |
| `UrbanSiteType.Disposal` | 同上 | `siteType` = `2` |

码表卡口与成品相同，但 **Converter / payload.From\* 各写一套**（Q3），不要一个类型靠后缀分叉。

实现为特定 Converter（目标 payload 的 `From*` 委托它，或 static 转换类型）。Worker **禁止**逐字段写萧山码；**禁止**把 Converter 注册成 Transient/Singleton。

现网 `GovSyncWeightPayload.FromRecord` 将 `InOutType` 写死为 0：落地时删掉该硬编码，改走 Converter。

## `UrbanPassageRecord` → 卡口/成品（摘录）

权威：场地 SyncDoc + 设计稿 §4–5。进出实体无 `goodsWeight`：卡口/成品该字段可选，**缺省不传或省略**，不要填 0 假装过磅。

| 实体 | 萧山 |
|------|------|
| `PlateNumber` | `carNo` |
| `PlateColor` | `carNoColor` |
| `VehicleType` | `carType` |
| `CapturedAt` | `snapTime`（`yyyy-MM-dd HH:mm:ss`） |
| 附件大图、小图 | `snapImages` Base64 数组，约定 `[大图, 小图]`；有则编、无则不凑 |
| `UrbanInOutType` | 经 Converter → `deviceID`：`Enter` → `01`，`Exit` → `02`（不要用 `DeviceCode` 表示进出） |
| `UrbanSiteType` | 经 Converter → `siteType`：`Construction` → `1`，`Disposal` → `2` |
| 配置 | `areaCode`（如 `330109`）、`spaceName` 可选 |
| 仅成品 | `buildLicenseNo` 后缀 `-02` |

成功：`code == 200`。卡口出队与成品出队 **分开实现**（可重复）。**不要**让 `GovSyncManager.GetPendingRecordIdsAsync` 只扫称重表却用进出 payload，也 **不要**一个 Worker 方法里 if 卡口/成品。
