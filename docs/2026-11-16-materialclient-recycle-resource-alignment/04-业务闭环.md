## 总览：四页 × 市接口

当前 Web 只覆盖「成品出厂销售」主链；渣土进厂 / 物料进场 / 废弃物 / 回填不在四页内。

```text
车辆信息池 ──► §2.6（车辆基础，按需）
     │              本地皮重另供算净重（§2.6 无皮重字段）
合同目录   ──► §2.4 + §2.7（销售合同 + 附件）
生产管理   ──► §2.5（成品日生产量）
运输清单   ──► §2.2（成品销售车次；工控毛重落点）
                 │
工控毛重+车牌+现场照片 ──①──► 我方平台（算净重、落运输清单）
我方 Worker              ──②──► 市平台 V1.0
```

| 页面 | 角色 | 市接口 | 工控？ |
|------|------|--------|--------|
| 车辆管理 | 车辆信息池（查皮重） | §2.6 | 否 |
| 合同管理 | 销售合同目录 | §2.4 / §2.7 | 否 |
| 生产管理 | 成品日产量 | §2.5 | 否 |
| 运输清单 | 出厂车次履约 | §2.2 | **是（毛重入口）** |

未接页面、本闭环 **Out-of-Scope**：§2.1 渣土接收、§2.3 物料进场、§2.8 废弃物、§2.9/§2.10 回填。

## 字段对照（页面 → V1.0）

### 1. 车辆管理 → §2.6 + 本地净重算法

页面字段（信息池）：车牌号、皮重(吨)、运输人、电话、车辆状态、录入时间、启用。

| 页面字段 | §2.6 | 说明 |
|----------|------|------|
| 车牌号 | `carNo` | 必填对齐 |
| 运输人 | `ownerName`（INFERRED） | 市接口是「车主姓名」；页面为运输人，语义是否等同 PENDING |
| 电话 | `ownerPhone` | 对齐 |
| — | `companyName` | 页面无「所属公司」；上报时需配置或另字段 |
| — | `approvedLoad` | 市接口「额定载重」；**不是**页面皮重 |
| — | `vehicleModel` | 页面无燃油/新能源；缺省策略 PENDING |
| **皮重(吨)** | **不进 §2.6** | 仅本地：接收时 `净重 = 毛重 − 皮重`，再写入运输清单 / §2.2 |
| 车辆状态 / 启用 | 无直接字段 | 本地门闩：未启用或未命中则拒收工控上传 |

| 产品明细.name / usage / unitPrice / quantity / amount | `contractDetail` JSON | |

| 页面字段 | §2.5 | 说明 |

| 生产日期 | `manufactureDate` | |

### 4. 运输清单 → §2.2（主履约）

页面字段：车牌号、合同编号、产品、产品净重/吨、起点、卸点、出货时间、出货凭证、收货时间、收货凭证；（筛选还有运输人、运输状态、上报状态）。

| 收货凭证 | `receivingProof` | Web 补全 |

## 端到端时序（闭环）

```text
A. 准备（可并行，均可先报市平台）
   车辆池录入车牌+皮重+启用  → 可选 §2.6
   合同新建+附件             → §2.7 再 §2.4
   生产管理登记日产量         → §2.5

B. 过磅（工控 MaterialClient.Recycle）
   上传：车牌 + 毛重 + 现场照片（+时间）
   不做：合同/产品/收货/皮重/净重

C. 我方接收
   1) 车牌命中启用车辆池 → 取皮重
   2) 净重 = 毛重 − 皮重（毛≤皮则拒收/挂起）
   3) 建/更运输清单行：毛、皮、净、出货时间、出货凭证就绪
   4) 合同/产品/收货仍空则本地「待补全」，不抢报 §2.2 或仅报出厂最小集（策略 PENDING）

D. Web 运输清单补全
   合同编号、产品、（可选）单价金额、收货时间/凭证、卸点等

E. Worker 第二跳
   出厂：组装 §2.2（必填 net/outTime/outPhotos/carNo/productName/pointNumber/dataNo）
   收货后：同一 dataNo 再调 §2.2 补 consignee* / receiving*
```

闭环判定：

1. 有车可查皮（启用池命中）  
2. 有次进清单（工控上传成功且净重合法）  
3. 有合同/产品可报（清单补全或规则默认）  
4. §2.2 发送状态闭合；失败留我方可重试  
5. （并行）合同 §2.4、日产量 §2.5、车辆 §2.6 各自状态闭合  

## 重量口径（ADOPTED，不变）

| 量 | 来源 | 落点 |
|----|------|------|
| 皮重 | Web 车辆信息池 | 池表；带入车次 / 可选 §2.2 `tareWeight` |
| 毛重 | 工控 | 车次表；可选 §2.2 `grossWeight` |
| 净重 | 平台 `毛 − 皮` | 运输清单「产品净重」；§2.2 必填 `netWeight` |

注意：V1.0 示例数值偏大（如 20000），与页面「吨」小数并存 → **上报单位（吨 vs kg）PENDING_VALIDATION**，实现前必须与市平台确认。

## 数据依赖（组装 §2.2 时）

```text
运输清单.车牌 ──查找──► 车辆池.皮重
运输清单.合同编号 ──查找──► 合同.收货地址 / 产品明细 / 单价
运输清单.产品 ──宜属于──► 合同.产品明细 或 生产管理曾用产品名
工控.现场照片 ──► 出货凭证 ──► §2.2 outPhotos
```

独立建表（ADOPTED）：四类业务表 + 同步状态表；逻辑 Id 关联，无数据库外键。
