# 00 调研总览 — Recycle 实验口授权发布

> 生命周期：`ACTIVE`  
> 研究状态：2026-11-18 实验口日志与配置已对齐。真实 5020 授权码走完客户端验签仍是 `PENDING_VALIDATION`。  
> 类型：发布核对单（非 OpenSpec change，非产品通过）

## 1. 这条链路

Recycle 桌面（产品码 5020）在线激活：

```
MaterialClient.Recycle
  POST {UrbanManagement:BaseUrl}/api/urban/auth/activate
    → 192.168.3.138:5333 网关
    → um-ingest
  POST {PublicApiServiceAuth:BaseUrl}/Api/Auth/ActivateUrban
    → 192.168.3.135:8551
```

客户端只使用 `UrbanManagement:BaseUrl`。`BasePlatform:BaseUrl` 不参与这次激活。

## 3. 结论

| # | 结论 | 状态 |
|---|------|------|
| C1 | 界面「无法连接到授权服务器 / 无法连接到授权服务」是客户端把 Refit 异常折叠后的文案。404、401、500、连接被拒绝都会变成这一句 | `CONFIRMED` |
| C2 | 138 主机和 Ingest 容器都能打开 `192.168.3.135:8551`。空的 `PublicApiServiceAuth:BaseUrl` 会在容器内落到 `http://localhost` | `CONFIRMED` |
| C3 | 135 站点 `appsettings.json` 若没有 `PublicApiServiceAuth`，中间件仍按启用处理，空密钥使 `/Api/Auth` 一律 401 | `CONFIRMED` |
| C4 | 只重建 `um-ingest` 不会跑 EF 迁移。`GovProjects` 缺 `ProductCode` 时，PublicApi 已签发并删掉一次性授权码，Ingest 再返回 HTTP 500 | `CONFIRMED` |
| C5 | 验签公钥在 `Jwt:PublicKey`，进程启动时读一次。Recycle 输出目录没有这段时，激活成功也会报「授权公钥未配置，无法验证」 | `CONFIRMED` |
| C6 | 换新的未使用 5020 授权码、重启已带公钥的客户端后，能否进入称重主窗 | `PENDING_VALIDATION` |
