# 05 · 入站来源枚举（区分 Legacy）

**状态**：新增需求（2026-09-03）  
**归属**：与 INT-006 / `LegacyGovSyncAppService` 同 change 落地；**不是** `fix-urban-weighing-receive-legacy-compat`（该 change 只放宽 Modern Receive 线格式）。

## 为什么要枚举

Legacy `/Api/Post` 与 MaterialClient Modern `Receive` 最终都写入同一张 `UrbanWeighingRecord`。列表、审批、排障、出站策略需要**稳定区分**记录来自哪条入站通道。

现有 `SubmitMachineCode` 是自由字符串（机器溯源），**不得**兼任通道枚举。

## 建议形状（默认，可改名）

```csharp
namespace UrbanManagement.Core.Entities.Enums;

/// <summary>
/// 称重记录服务端入站通道（谁调用了入库路径）。
/// </summary>
public enum UrbanWeighingIngestSource
{
    /// <summary>Modern：MaterialClient 等走 ReceiveAsync 标准契约。</summary>
    Modern = 0,

    /// <summary>Legacy：LegacyApiController / LegacyGovSyncAppService（旧 /Api/Post）。</summary>
    Legacy = 1,

    /// <summary>Migrated：XiaoShanServe Gov_SyncData 等历史批迁（见 06）。</summary>
    Migrated = 2
}
```

实体属性建议：

| 位置 | 建议 |
|------|------|
| `UrbanWeighingRecord.IngestSource` | `UrbanWeighingIngestSource`，**non-nullable**，默认 `Modern` |
| DB 列 | `IngestSource` int；既有 UM 行 migration 默认 `0`（Modern） |
| `UrbanWeighingRecordReceiveInputDto.IngestSource` | 可选；缺省 `Modern` |
| 输出 DTO / 列表 | 暴露同名，便于 Web 过滤（若本期不做 UI，至少实体+Receive 写入） |

对齐既有命名习惯：与 `PassageSource`、`UrbanSiteType` 同属 `Entities.Enums`，存 int。

## 谁赋值（硬规则）

| 路径 | 赋值 |
|------|------|
| `LegacyGovSyncAppService` → 调 `ReceiveAsync` 前 | **必须** `IngestSource = Legacy` |
| MaterialClient / 其它 Modern Receive | **必须** `Modern`；对外忽略客户端伪造的非 Modern |
| XiaoShanServe `Gov_SyncData` 批迁（[06](./06-XiaoShanServe历史数据迁移.md)） | **必须** `Migrated` |
| 幂等更新（同 `ClientRecordId`） | **不**因重试改写已有 `IngestSource`（首写为准） |

## 明确不做

| 做法 | 原因 |
|------|------|
| 用 `SubmitMachineCode = "Legacy"` 区分 | 弱类型、难过滤、易被覆盖 |
| 放进 `ExtraProperties` 而不建列 | 列表/索引差；通道是一等语义 |
| 枚举混入 `SyncStatus` / `SiteType` | 语义不同 |
| 本枚举表示政府 `dataSource` 出站字段 | 出站另有协议；入站通道 ≠ 政府 dataSource |

## 对转换核心的影响

`LegacyGovSyncAppService` 步骤在存图/`ClientRecordId` 之后、调用 `ReceiveAsync` 时，Receive 入参带 `IngestSource = Legacy`（或 Receive 增加仅内部可见的重载/`FromLegacy(...)` 工厂）。  
Modern `ReceiveAsync` 创建实体时写入 `Modern`。
