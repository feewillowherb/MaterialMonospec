# 00 · 调研总览：XiaoShanServe 入站转发至 UrbanWeighingRecord

**日期**：2026-09-03  
**类型**：代码考古 + 同机部署转发方案摸底（非 PRD / 非 OpenSpec）  
**状态**：调研完成，供后续 `/opsx:propose` 或消化 [INT-006](../intake/2026-09/INT-006-legacy-gov-sync-reimplementation.md)  
**范围仓库**：`repos/Fdsoft.Weight.GovClient/FdSoft.MaterialSys.Gov.XiaoShanServe`、`repos/UrbanManagement`

## 一句话

旧报文 → `UrbanWeighingRecord` 的**转换业务核心**落在 UM 的 `LegacyGovSyncAppService`（INT-006）：校验 AccessCode、存图、拼 `ReceiveInputDto`、调用 `ReceiveAsync`。`LegacyApiController` 只负责 HTTP/JSON 解析与旧版响应形状；XiaoShanServe 同机仅作切流（反代/退役），**不**承担转换逻辑。

## 已确认决策

| # | 决策 | 状态 |
|---|------|------|
| D1 | 转换核心 = `LegacyGovSyncAppService.ProcessLegacyRequestAsync` | ✅ 2026-09-03 |
| D2 | 落库只走 `IUrbanWeighingRecordAppService.ReceiveAsync`（+ 附件）；禁止 `GovSyncData` 双写 | ✅ 对齐 D18/D19 |
| D3 | `LegacyApiController` 保持薄：解析 → 调 Service → 映射 `success/msg/code` | ✅ |
| D4 | 新增枚举区分入站通道：`UrbanWeighingIngestSource`（`Modern` / `Legacy` / **`Migrated`**），落 `UrbanWeighingRecord.IngestSource`；在线 Legacy 写 `Legacy`，批迁写 `Migrated` | ✅ 2026-09-03；`Migrated` 随 06 补充 |
| D5 | XiaoShanServe `Gov_SyncData` 批迁至 `UrbanWeighingRecord`（丢弃 `sourceData`；主键重生成；`ClientRecordId=Empty`；成功行 `Success`） | ⏸ **挂起** → [INT-007](../intake/2026-09/INT-007-xiaoshanserve-govsyncdata-migrate.md) |

## 落地规模（参考）

**M–L**（约 15万–100万 token）：当前推进以 **在线 Legacy + IngestSource** 为主。历史批迁（原 L 增量）已挂起 INT-007，不计入本期。

## 结论摘要

| 项 | 结论 |
|----|------|
| **转换核心** | `repos/UrbanManagement/.../LegacyGovSyncAppService.cs`（现 stub 501 → 实装） |
| Controller | `LegacyApiController`：路由 `/Api/Post`、解析、旧响应；**无**业务映射 |
| Modern 落点 | `ReceiveAsync` → `UrbanWeighingRecord`；附件先 `IFileService` |
| XiaoShanServe | 不写转换；切流后停其 `GovSyncData` 出站，避免双报 |
| 字段鸿沟 | `ClientRecordId` / `ProId` / `AttachmentIds` / `siteType` / 重量 — 均在 Service 内解决 |
| **入站区分** | 实体枚举 `UrbanWeighingIngestSource`：`Modern` / `Legacy` / `Migrated`（见 [05](./05-入站来源枚举.md)、[06](./06-XiaoShanServe历史数据迁移.md)） |
| **历史迁移** | ⏸ 挂起 [INT-007](../intake/2026-09/INT-007-xiaoshanserve-govsyncdata-migrate.md)；细节仍见 [06](./06-XiaoShanServe历史数据迁移.md) |
