# 03 · 方案对比与推荐

## 分层（已确认）

| 层 | 类型 | 职责 |
|----|------|------|
| `LegacyApiController` | HTTP 门面 | `JsonElement` → `LegacyGovSyncRequestInputDto`；返回旧版 `{ success, msg, code }` |
| **`LegacyGovSyncAppService`** | **转换业务核心** | AccessCode 校验（忽略凡东码）、重量/SiteType/`ClientRecordId`、UM 存图(Lpr)、`IngestSource=Legacy`、Receive；拒收 → 暂存表 |
| `IUrbanWeighingRecordAppService` / `IFileService` | Modern 能力 | 幂等入库与附件；写入 `IngestSource`（对外路径固定 `Modern`） |

**禁止**把映射/幂等键生成写进 Controller；Serve 只做 HTTP 转发。

## 方案一览

| 方案 | 做法 | 状态 |
|------|------|------|
| **B. UM Legacy（INT-006）** | 转换核心在 `LegacyGovSyncAppService` | **已确认（业务）** |
| **A/C 切流 = D11** | 同机异端口；Serve→UM **HTTP 转发** | **已确认（运维入口）** |
| 直连 Modern Receive | 改客户端协议 | 非本需求 |

均须：**只写 `UrbanWeighingRecord`，禁止 `GovSyncData` 双写**；政府出站只走 UM Worker。

## A · 同机异端口 HTTP 转发（已确认切流 = D11）

```text
Client → XiaoShanServe:{portA}/Api/Post
       →（仅转发，无映射/无落盘）HTTP → UrbanManagement:{portB}/Api/Post
       → LegacyGovSyncAppService …
```

- 同机、**端口不同**；客户端可继续打 Serve 端口。
- Serve **禁止**：字段映射、TempUpload 落盘、写 `GovSyncData`、出站政府。
- 转换与拒收暂存全部在 UM。

## B · `LegacyGovSyncAppService` 实装（已确认）

```text
Client →（反代或改绑）→ LegacyApiController /Api/Post
       → LegacyGovSyncAppService.ProcessLegacyRequestAsync   ← 转换核心
            查 GovProject by AccessCode（失败 → 拒收暂存含 Base64 图，return 失败响应）
            IFileService 存图到 UM（Serve 不落盘）
            构造 ReceiveInputDto（ClientRecordId=NewGuid；IngestSource=Legacy）
            ReceiveAsync → UrbanWeighingRecord
            return LegacyGovSyncOutputDto
       → Controller 映射旧版 JSON
```

Service 内建议顺序（实现时写入 tasks）：

1. 拒收：无 `buildLicenseNo`（**忽略** `fdBuildLicenseNo`）→ **写拒收暂存**（§2.2）→ 返回失败  
2. 解析重量（对齐 XiaoShanServe：`grossWeight>0` 覆盖）与 `WeighingTime`；失败同上暂存  
3. 查 `GovProject` by AccessCode → `ProId` / `ProName`；查不到 → 暂存  
4. **UM** 存图，`AttachType.Lpr`（全部）→ `AttachmentIds`（**禁止** Serve 落盘）  
5. **`ClientRecordId = Guid.NewGuid()`**；**`IngestSource = Legacy`** → `ReceiveAsync`  
6. 异常 → 尽量暂存 + `success=false` + 明确 `msg`/`code`  

**同机切流（D11）：** Serve:{portA} HTTP 转发 → UM:{portB}/Api/Post；Serve 侧**不**复制上述步骤；端点**不鉴权**（D10）。

## A / C（说明）

- **切流**已定为同机异端口 HTTP 转发（上节 A / D11），不是「Serve 内做转换」。  
- **直连 Modern Receive**：非本需求。

## 明确不做

| 做法 | 原因 |
|------|------|
| 转换写在 `LegacyApiController` 或 XiaoShanServe `ApiController` | 违背已确认 D1 |
| 用 `SubmitMachineCode` 字符串区分 Legacy | 违背 D4；见 [05](./05-入站来源枚举.md) |
| XiaoShanServe / 反代层本地落盘 jpg | 违背 D8；权威在 UM |
| Serve 内做凡东码换码或字段映射 | 违背 D1/D12；只转发 |
| 给 Legacy `/Api/Post` 加登录鉴权 | 违背 D10 |
| 拒收只打日志不落暂存（无图） | 违背 D7；开发无法补救 |
| Receive 同时 Insert `GovSyncData` | 违反 D19；双报风险 |
| 把 `snapImages` 路径塞回实体 | 实体已无 `SnapImages` |
| 共享 SQLite 直写对方表 | 绕过 Receive 幂等与附件模型 |
| 用 tuple 做映射返回值 | 仓库 C# 约定：命名 `record` |
