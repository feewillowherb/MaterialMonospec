# 05 — 快速参考（AI 生成时先读本页）

用本页填空。细节回 `03`，字段回 `02`，图模型回 `06`，冲突回 `01`。Sample 形状见 `04`。

---

## 一分钟决策

| 用户大概在说 | Family |
|--------------|--------|
| 打开/登录/截图/看页面有没有数据 | observe |
| CSV/Excel/JSON 进库或进文件存储 | ingest |
| 打 API、读缓存、健康检查 | probe |
| 页面 vs 库 vs 接口是否一致 | reconcile |
| 转换格式、生成夹具、导出到 `_tmp` | transform |
| 又写又看 | **两条** Graph（Goal 不同） |
| 「别用旧验法」 | 旧 Graph → `retired`，不是并存 active |

副作用默认：observe/probe/reconcile = 只读；transform = 写本地；ingest = 写系统（先 dryRun）。

口述落点：可重复可失败 → Node；「你看对不对」→ **Gate**；失败史 → `docs/`；进业务 → OpenSpec。

## Brief 填空（复制后填）

```yaml
id:                     # kebab-case，字母开头
family:                 # observe | ingest | probe | reconcile | transform
goal:                   # 互斥槽；同 goal 不得两个 active
status: active
purpose:                # 一句
sockets:
  start:                # 例 session-anonymous / csv-raw
  end:                  # 例 observe-captured / table-upserted
cook: new-object        # in-place | new-object
nonGoals:
  - 不修改业务代码
  - 不提交 secrets/runs
  - 不替代规范与 CI
  - Agent 不宣布 L3 通过
environment: local      # 非 local 必须人闸确认
stopOnError: false      # ingest 写库建议 true
target:
  # observe: baseUrl, loginPath
  # ingest: table, matchKeys, sourcePath
  # probe: baseUrl, endpoints[]
  # reconcile: left, right, alignKey
  # transform: input, output
secretsKeys: []         # 只写键名
steps: []               # id + name + 路径或映射
collectors: []          # 见下表
adapters: {}
humanGates:
  - missing-secrets
  - acceptance
failurePolicy:
  retries: 2            # ingest 写库常用 0
  stopOnError: false
```

## 默认证据（按族）

| Family | 必做 collector | 常见可选 |
|--------|----------------|----------|
| observe | screenshot, http, logs | console, websocket, db-proof |
| ingest | summary.json, report.md | dry-run diff 样例行 |
| probe | request-response 全文（截断+脱敏） | 延迟、headers |
| reconcile | left 摘录, right 摘录, diff | 截图辅助 |
| transform | 输入哈希, 输出路径, 行数/字节 | 抽样预览 |

必做 = 必须有文件。没有数据 → `count: 0` / `source: missing`，不是省略。

**先挂钩，再动作。**

## 目录最小集

```text
pipelines/<slug>/                 # = Graph 实例
  pipeline.md                     # Graph 投影 + mermaid Cook chain
  config.yaml
  secrets.example.yaml
  acceptance.md
  scripts/                        # 隔离；experimental
  secrets.local.yaml              # 仅本机
  runs/<yyyy-MM-ddTHHmmss>/       # 仅执行时创建；new-object 证据
```

gitignore：`**/secrets.local.yaml`、`**/runs/`。

Context 优先级：标记 → 结构指纹 → 显式指针 → 显示名（禁止唯一键）。歧义则停。

拆文：满足 `06` **≥2** 条硬边界才拆；不要一句话一个 md。

## 状态机（所有族）

```text
init → load_config → resolve_secrets → Bind/preflight
    → Cook/execute → Validate+evidence → write_report
    → Gate/await_user_acceptance → end
```

报告默认句：`等待用户验收，尚未通过。`  
问：`请验收：pass / fail + 对象与原因。`

## 人闸清单

| 何时 | 做什么 |
|------|--------|
| 缺密钥/连接串/路径 | 问；不猜 |
| 不知 URL/表名/字段；Context 歧义 | 问；不编造、不靠显示名 |
| slug 目录已存在；同 Goal 已有 active | 覆盖 / 换名 / 取消；或旧图 retired |
| environment ≠ local | 确认 |
| ingest 且 dryRun=false | 确认写入 |
| run 结束 | 验收（Gate 不可静默） |

## 生成检查清单

- [ ] 已分类并复述 family + Goal  
- [ ] brief 含 sockets / cook 语义；填完再脚手架  
- [ ] 可提交文件无密钥  
- [ ] runbook 步骤与 config 对齐；Wire 上 Socket 对齐  
- [ ] required collector 都有输出路径  
- [ ] mermaid Cook chain（或 ASCII 降级声明）  
- [ ] 非目标已写；脚本在隔离区  
- [ ] 同 Goal 无第二个 active  
- [ ] 摘要含路径与「是否立即执行？」  

---

## 禁止

编造路由/表名 · 密码进 markdown · 覆盖旧 run · 静默跳过缺证 · Agent 自称验收通过 · 脚本进业务包 · Sample 假值当真实默认 · 一条 slug 又导入又做 UI 且无 Socket · 同一 Goal 两个 active · 显示名当唯一键 · 一句话一个文档 Node · 协议只活在调研夹
