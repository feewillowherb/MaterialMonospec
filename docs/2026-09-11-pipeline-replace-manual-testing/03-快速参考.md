# 快速参考

## 命令

| 意图 | 入口 |
|------|------|
| 生成新图 | `/gen-pipeline` 或 `/gen-<family>-pipeline` |
| 执行现有图 | `/run-pipeline <domain>/<slug>` |
| 权威约定 | `pipelines/AGENTS.md` |
| 哲学深潜 | `docs/2026-08-13-ai-pipeline-design-philosophy/` |

Family：`observe` | `ingest` | `probe` | `reconcile` | `transform`

## 落盘位置

```text
pipelines/graphs/<domain>/<slug>/
  pipeline.md
  config.yaml          # created + graph.*
  secrets.example.yaml
  secrets.local.yaml   # gitignore
  runs/<yyyy-MM-ddTHHmmss>/
```
