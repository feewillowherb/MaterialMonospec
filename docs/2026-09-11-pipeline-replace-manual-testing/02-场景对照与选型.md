## 3. 选型决策树（压缩）

```text
要改产品代码吗？
  是 → OpenSpec，不要塞进 pipeline
  否 → 是否已有 active Graph 同 goal？
         是 → /run-pipeline
         否 → 归 family → /gen-<family>-pipeline → 人确认后再 /run-pipeline
```

## 4. 证据包里通常有什么

因 Graph 而异，常见：

- `report` / 日志（stdout、stderr、dotnet-build）  
- HTTP JSON 摘录（`http/`）  
- 截图（observe）  
- dryRun 计数 / diff（ingest、reconcile）  

**人闸**：只认本次 `runs/<timestamp>/`，不认聊天里的「刚才绿了」。
