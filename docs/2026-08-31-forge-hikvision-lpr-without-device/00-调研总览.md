# 伪造 Hikvision LPR 测试数据（不依赖真机抓拍）

日期：2026-08-31  
范围：`MaterialClient.Urban` 卡口 / 成品进出本地落库与联调；对照 HCNetSDK V6.1.9.48 win64 文档包。

## 结论（先读）

| 目标 | 推荐做法 | 是否需要真机 |
|------|----------|--------------|
| 客户端本地走完整识别事件 → 卡口/成品 | **POST** `/api/lpr/test-passage` | **否** |
| 查询 / 保存整份 Settings | **GET** `/api/settings` · **POST** `/api/settings` | **否** |
| 通用伪造识别事件 | **POST** `/api/lpr/test-plate` | **否** |
| 解析海康报警二进制 | 单测 + `HikvisionGolden` | **否** |
| 设置页「测试抓拍」 | `TriggerCaptureAsync` | **是** |
| 客户端 HTTP 上云到 UM 卡口/成品 | OpenSpec §7 未完成 | N/A |

**一句话：**卡口/成品联调走 `LicensePlateRecognizedEventData`；用 `/api/lpr/test-passage` 发事件，用整份 Settings 的 GET/POST 准备 LPR 行。诊断 API 只用 **GET / POST**，不用 PUT。
