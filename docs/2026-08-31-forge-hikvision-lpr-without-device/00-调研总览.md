# 伪造 Hikvision LPR 测试数据（不依赖真机抓拍）

日期：2026-08-31  
范围：`MaterialClient.Urban` 卡口 / 成品进出本地落库与联调；对照 HCNetSDK V6.1.9.48 win64 文档包。

## 结论（先读）

| 目标 | 推荐做法 | 是否需要真机 |
|------|----------|--------------|
| 客户端本地生成卡口/成品 `UrbanPassageRecord` | **POST** `MinimalWebHost` 的 `/api/lpr/test-plate`，`DeviceName` 对齐设置里的 LPR 行名 | **否** |
| 解析海康报警二进制（ITS / Upload Plate） | 单测 + `HikvisionGolden` 合成 fixture | **否** |
| 设置页「测试抓拍」按钮 | 走 `ILprDevice.TriggerCaptureAsync` | **是**（真机或可登录的仿真机） |
| 客户端 HTTP 上云到 UM 卡口/成品 Receive | OpenSpec tasks **7.1–7.2 未完成**；当前 `UrbanServerUploadService` 只上传称重 | N/A（缺口） |
| 用 SDK 主动向客户端「灌」报警回调 | 官方 Demo 只做布防收真实设备报警；**无**独立「伪造成功回调」API | 不推荐作为日常联调路径 |

**一句话：**伪造「海康识别结果」应对齐产品事件总线 `LicensePlateRecognizedEventData`，不要假装在 DLL 里造 SDK 回调；Urban 诊断口已经提供 HTTP POST 注入。
