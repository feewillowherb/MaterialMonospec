# 事件链路与注入点

## 真机路径（Hikvision）

```text
设备报警
  → HCNetSDK MSGCallBack（COMM_UPLOAD_PLATE_RESULT / COMM_ITS_PLATE_RESULT）
  → HikvisionLprService.MessageCallback / ProcessRecognizedPlate
  → ILocalEventBus.PublishAsync(LicensePlateRecognizedEventData)
       DeviceName = config.Name（按设备 IP 反查配置）
       LprImagePath = 可选本地附件路径
  → UrbanPassageLprHandler.HandleEventAsync
       SiteType == Scale → return（不建进出）
       SiteType == Checkpoint → PassageSource.Checkpoint
       SiteType == FinishedProduct → PassageSource.FinishedProduct
  → IUrbanPassageRecordService.CreateFromLprAsync
  → UrbanPassageRecordCreatedEventData → UI 刷新卡口/成品 tab
```

关键实现：

- `HikvisionLprService.PublishPlateRecognizedEvent`：组装并发布 `LicensePlateRecognizedEventData`
- `UrbanPassageLprHandler`：`FindByDeviceName(configs, eventData.DeviceName)`；找不到或地磅场地则跳过

## 伪造路径（推荐，不经 SDK）

```text
HTTP POST /api/lpr/test-plate
  → MinimalWebHostService 构造 LicensePlateRecognizedEventData
  → 同一 ILocalEventBus
  → UrbanPassageLprHandler（同上规则）
```

与真机的差异：

| 字段 | 真机 Hik | test-plate |
|------|----------|------------|
| `DeviceName` | 配置表 `Name` | 请求体 `deviceName`（默认 `"TestApi"`） |
| `LprImagePath` | 可有图 | **当前不传**（无附件） |
| `PlateColor` / `VehicleType` | SDK 解析 | 请求体未暴露；handler 用默认「无 / 大车」等 |
| `DeviceType` | Hikvision | 默认可为 Hikvision |

因此：**伪造的是「识别业务事件」，不是「HCNetSDK 回调字节流」。** 对卡口/成品本地落库与 UI 列表足够；测附件上传需另补图片路径（见 04）。

## 其它注入点（不优先）

| 机制 | 说明 | 局限 |
|------|------|------|
| 设置页「测试抓拍」`TestLprCaptureCommand` | 调真实 `TriggerCaptureAsync` | 依赖设备在线 |
| `MockHikvisionLprService.SimulatePlateRecognition` | 发 **MessageBus** `LicensePlateRecognizedMessage` | **不**走 `ILocalEventBus`；`UrbanPassageLprHandler` **收不到** |
| `AttendedWeighingService` 订阅 | 地磅称重用同一 EventData | SiteType=Scale 时进出 handler 会跳过 |

## 配置前置条件（进出）

设置 → 车牌识别至少一行：

- `Name`：与 POST `deviceName` **完全一致**
- `SiteType`：`Checkpoint`（卡口）或 `FinishedProduct`（成品）；**不能**是 `Scale`
- Urban 进出语义：`UrbanInOutType` / `UrbanSiteType`（JSON 缺省时有默认 Enter + Construction）

`UrbanLprCapabilities.FromConfigs` 决定 UI 是否显示卡口/成品专用 tab；无对应 SiteType 行则 tab 能力为 false。
