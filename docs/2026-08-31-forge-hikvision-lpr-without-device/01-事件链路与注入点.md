# 事件链路与注入点

## 真机路径（Hikvision）

```text
设备报警
  → HCNetSDK MSGCallBack
  → HikvisionLprService → LicensePlateRecognizedEventData
  → UrbanPassageLprHandler（SiteType≠Scale，FindByDeviceName）
  → CreateFromLprAsync → UI
```

## 诊断路径（推荐，不经 SDK）

```text
1) GET  /api/settings
2) 改 LicensePlateRecognitionConfigs（含 Checkpoint / FinishedProduct）
3) POST /api/settings   （整份 Settings）
4) POST /api/lpr/test-passage
     siteType = Checkpoint | FinishedProduct
     → 解析匹配的 config.Name 作为 DeviceName
     → Publish LicensePlateRecognizedEventData
     → UrbanPassageLprHandler（与真机同一 handler）
```

可选：`deviceName` 指定某一行；省略则取该 `SiteType` 的第一行。

## 通用事件注入

```text
POST /api/lpr/test-plate
  → LicensePlateRecognizedEventData（须自行保证 DeviceName 命中配置）
```

## 配置前置

`UrbanPassageLprHandler` 要求：

- `FindByDeviceName` 命中
- `SiteType` 为 `Checkpoint` 或 `FinishedProduct`（`Scale` 直接 return）
