# 06 日志样本里的重量曲线

> 样本：`D:\新建文件夹\固废\1110\` 下四份应用日志，日期 2026-10-14、10-22、10-31、11-01。  
> 只使用地磅状态行里的重量。车牌、抓拍、道闸、上传不进入这篇。  
> 四份文件都没有 `[DBG]`，也没有 `Weight stability:`。上磅和下磅的中间点没有落盘。  
> 这不是 OpenSpec change。模拟的单车基准固定为约 45 吨。下面的建单吨数只说明这四份文件里写了什么，不替换基准。  
> 繁忙叠车的地磅日志当前没有，也无法再提供。

## 1. 日志实际留下的重量

地磅读数进管道之后，Information 级别只在状态切换时写一个重量。能对上的行是：

| 行 | 这个数是什么 |
|----|----------------|
| `Entered WaitingForStability state (ascending), weight:` | 状态翻到上磅时，外侧重量流配上的那个读数 |
| `Converting WaitingForStability -> WeightStabilized: weight=` | 已经判稳、称重单还没写上的那一小段。约每 200 ms 一条，重量是当时的活读数 |
| `creating record with weight:` | 写入称重单的稳定重量，取那一窗的中点 |
| `Entered WaitingForDeparture state (descending), weight:` | 状态改名时配上的活读数 |
| `Normal flow completed ... OffScale state, weight:` | 状态翻到下磅时配上的活读数 |

状态流和这条外侧重量流是两段各自按约 200 ms 取末点的缓冲。下磅那一行的吨数可以还停在阈值上方一点，它是配对到的邻近读数，不能当成「空磅阈值等于这个数」。上磅沿多次出现 0.3 吨档，说明翻状态时读数已经在零点几吨。

四份文件合计：上磅 268 次，建单 264 次，正常下磅 266 次，`Abnormal departure from WeightStabilized` 1 次。

## 2. 一辆车能连起来的形状

有建单且有正常下磅的 262 笔，四个锚点是齐的。锚点之间没有采样。

```text
读数
  ^
  |              ________________________  建单重量。判稳后这一小段极差 ≤ 0.1 吨
  |             /
  |            /   7–21 秒，日志里没有点
  |     ______/
  |____/      \                        \____
  | 0.3–0.7 吨  \                        \  下磅配对读数，多数已在 1 吨以内
  +------------------------------------------------> 时间
     上磅沿      约 13 秒后建单    再约 5 秒重量仍相同    之后才记到下磅
```

| 锚点 | 262 笔里看到的 |
|------|----------------|
| 上磅沿 | 全部低于 2.5 吨，中位 0.52 吨。没有一笔上磅日志直接跳到几十吨 |
| 上磅到建单 | 最短 7.2 秒，中位 13.1 秒，90 分位 16.4 秒，最长 21.1 秒 |
| 判稳那一小段 | 262 笔的 `Converting` 突发里，最大减最小都不超过 0.1 吨。中位约 27 条 |
| 建单到 `WaitingForDeparture` | 中位 5.3 秒。这期间重量变化最大 0.08 吨。日志写着 descending，读数仍是建单那一档 |
| 进入离开状态到下磅日志 | 中位 11.6 秒，最短 7.7 秒，最长 181 秒。中间形状没有点 |

下磅日志的配对读数：266 笔正常下磅里，138 笔在 0～0.5 吨，2 笔为负，126 笔高于 0.5 吨。高于 1 吨的 34 笔，最大 4.72 吨（2026-11-01 11:38:57）。这些是配对读数，下降斜坡本身仍没有采样。

例子（轻车，锚点齐）：

| 时刻 | 重量 t | 行 |
|------|--------|----|
| 2026-10-22 11:16:33 | 0.59 | 上磅 |
| 11:16:47 | 8.49 | 建单 |
| 11:16:52 | 8.49 | 状态改为离开，重量未降 |
| 11:17:03 | 0.08 | 下磅配对读数 |

## 4. 重车在判稳之后停得更久

从「状态改为离开」到「下磅日志」的时间，按建单重量分开：

| 这段时间 | 笔数 | 建单重量中位 |
|----------|------|----------------|
| 12 秒内 | 148 | 9.1 吨 |
| 12–20 秒 | 81 | 8.3 吨 |
| 20–40 秒 | 6 | 5.1 吨 |
| 40–90 秒 | 5 | 6.0 吨 |
| 90 秒以上 | 21 | 41.8 吨 |

建单重量 ≥ 40 吨的 12 笔，这段时间是 91～181 秒。轻车多数在判稳后大约十几秒内就记到下磅。重车的这一段里同样没有中间采样，所以分不出「车还停在磅上」和「车在慢慢开下去」。能确认的是：重车的下磅日志来得晚，而且进入离开状态时重量仍等于建单重量。

重车例子：

| 上磅 | 建单 t | 下磅日志 | 离开状态到下磅 |
|------|--------|----------|----------------|
| 2026-10-14 15:29:01 | 71.30 | 配对 0.14 吨 | 134 秒 |
| 2026-10-31 07:55:15 | 66.68 | 配对 0.79 吨 | 181 秒 |
| 2026-11-01 09:37:50 | 71.29 | 配对 0.25 吨 | 102 秒 |
