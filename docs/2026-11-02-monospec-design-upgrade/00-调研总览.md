## 一句话

**主要变更**是把本仓 Monospec 升级为 **BlenderTools-MonoSpecs** 的编排设计：权威分层（FEV / ICD / CED / DOCS）、IWE、机器可读 Pipeline Contract、DOCS Topic 卫生。

**本仓技术栈内容不变**，包括产品语言与框架、Node.js cook（`pipelines/AGENTS.md` §4）、子仓架构。BlenderTools 自己的技术栈（Python cook、DCC / 引擎域约定）不随 Monospec 一起迁入。

引入的是已稳定的判别，以及按本仓改写的契约。BlenderTools 中仍为 Proposed / PENDING 的整份 trait 不原样粘贴，也不把该状态升格为本仓 Established。本仓已有的 Intake、openspec-git、编码类 traits、`docs/AGENTS.md` 的 BMAD↔OpenSpec 路由继续保留。

| 结论 | 说明 |
|------|------|
